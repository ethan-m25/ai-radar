AI Controls Blender for 3D Rendering — Simon Willison Shows a New Workflow, Non-Developers Can Do 3D Too
clawii, Simon Willison published a blog post today: using ChatGPT Codex to make Blender render a "pelican riding a bicycle" 3D scene through natural language. This isn't just fun — it means AI can directly control complex 3D modeling software, and you don't have to learn Blender's intimidating interface or Python API. Whether you want product mockups, simple animations, or to turn ideas into 3D visuals, this could be a new path.
📍 Context · Blender is the open-source 3D creation suite — powerful but with a steep learning curve. Previously, to render something you either modeled by hand or wrote Python scripts. Now AI can call Blender's command line or Python API through natural language and auto-generate scenes. Simon demonstrated controlling Blender directly via Codex (ChatGPT's coding agent) on macOS, with surprising results.

Why this is worth a look

  • Natural language 3D modeling: You no longer need to learn Blender's shortcuts, material nodes, or renderer settings. Just say "render a pelican riding a bicycle with a beach background at sunset" and AI executes it. Simon's blog even shows iterative improvement: first add a background, then "make it better" — the final render is genuinely impressive.
  • Non-developer friendly: You don't need to know Python or Blender's API. Just type natural language instructions into Codex or Claude Code and AI calls Blender and outputs the result. Simon's prompt was: "Use the already installed /Applications/Blender to render a scene of a pelican riding a bicycle".
  • Broad potential applications: Product prototype visualization, presentation renders, simple animations, even as a "design assistant" for rapid iteration. For anyone doing product work, marketing, or personal projects, this could be a new productivity tool.
  • Ecosystem expansion signal: This isn't just Blender — it shows AI can control any complex software with a command-line interface or API. Future extensions could include CAD, video editing, audio processing, and more.

🎯 What you can do today

  1. If you're on macOS and have Blender installed (download from blender.org), open ChatGPT Codex or Claude Code and try something like Use the already installed /Applications/Blender to render a scene of a pelican riding a bicycle.
  2. Read Simon Willison's full blog post: TIL Using Blender with coding agents on macOS
  3. Try more complex prompts like "add a background", "change the lighting", "make the pelican fly". Simon showed how iterative prompting improves results.
  4. If you're not on macOS, try installing Blender on Linux and using a similar approach.

How it works technically: Codex (or Claude Code) understands the user's intent via natural language, then calls Blender's Python API (the bpy module) to generate the scene. Simon's prompt directly specified the Blender path, and the AI knew how to launch Blender and execute the Python script. It's essentially "AI as Blender's script writer" — but the user doesn't need to write the script themselves.

Limitations: Currently, AI's control over complex scenes is limited — it may struggle with fine-grained materials or animation. But Simon's iterative improvement demo shows that multiple prompts can progressively refine the output. Also, you need Blender installed locally (~500MB), and the AI needs permission to call system commands.

Honest caveat: This isn't a new product — it's a creative use of existing tools. But its emergence signals that AI is breaking out of "code generation" into "3D content generation." For non-developers, this is a cool toy worth trying, but it won't replace professional 3D workflows anytime soon.
