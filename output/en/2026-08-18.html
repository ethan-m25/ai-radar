👀 GPT-5.6 Sol price cut 50%: OpenRouter announces new pricing, HN 471 points

Pricing · API · Price war
📍 Context

OpenRouter is a third-party API provider for OpenAI models, offering flexible pay-as-you-go access. Today (Aug 18), OpenRouter announced a 50% price cut for GPT-5.6 Sol — from $0.20/M input tokens to $0.10/M input tokens. HN hit 471 points with 294 comments, and the community reaction is intense. This follows last month's 80% Luna price cut from OpenAI directly, signaling that the model price war is accelerating.

Why this matters
  • Price directly halved: GPT-5.6 Sol is OpenAI's latest flagship model. At $0.10/M input tokens, it's half what it cost a month ago. For heavy API users, this means thousands of dollars in monthly savings.
  • Price war signal: DeepSeek V4 Flash already hit the market at $0.435/M input tokens. The OpenAI alliance is responding via OpenRouter's price cut, and Chinese models like Qwen and DeepSeek are also dropping prices. The "cheap intelligence" era is accelerating.
  • What this means for clawii: If you call GPT-5.6 Sol through OpenRouter for vibe coding or office automation, your costs just halved. Even if you don't call the API directly, price drops push down costs across the entire ecosystem.
  • Non-developers benefit too: ChatGPT Plus subscribers won't see the cut directly, but cheaper API pricing means more developers building low-cost AI apps — and end users benefit eventually.
🎯 Action
  1. Check your OpenRouter account: Log in and verify the new pricing is active. If you use GPT-5.6 Sol, your costs just dropped by half.
  2. Re-evaluate API costs: If you use GPT-5.6 Sol for batch processing or automation, recalculate your costs. You might be able to scale up usage.

🔬 Deep dive

vs OpenAI official pricing: OpenAI's official API is still $0.20/M input tokens. OpenRouter's $0.10/M is 50% cheaper. OpenRouter is a third-party reseller, so there may be minor latency differences, but for most users it's indistinguishable.

Price cut comparison: Last month GPT-5.6 Luna dropped 80% (from $0.15 to $0.03). This month Sol drops 50%. OpenAI is clearly in an aggressive price war. Sol is the flagship model — stronger than Luna — so the value proposition just got much better.

Real impact for clawii: If you run an AI assistant through OpenRouter (e.g., using Codex to write scripts), your daily API cost drops from $10 to $5. That's real money over a month.

Honest caveat: Price cuts sometimes come with reduced service priority (e.g., lower queue priority). OpenRouter hasn't reported any such issues yet. Also, more users may flood in, potentially increasing API latency.
