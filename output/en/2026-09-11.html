Shopify Drops React Native for Swift + Kotlin — Because AI Agents Are Enough
Hey clawii — Shopify just announced they're moving back from React Native to separate Swift and Kotlin codebases. Not because React Native failed, but because AI agents have made the cost of maintaining two native codebases irrelevant. This is the first time a major company has overturned its cross-platform strategy purely because of agent capability. HN front page #2 with 1087 points.
📍 Context · React Native is Meta's cross-platform framework that lets you write one codebase for iOS and Android. Shopify adopted it in 2020, like many big companies before them. The core motivation was simple: "one codebase, half the engineering cost." Six years later, Shopify is reversing course: agents can now maintain two native codebases (Swift for iOS, Kotlin for Android) simultaneously, making the 2020 cost argument obsolete. This isn't a small team experimenting — it's one of the most engineering-efficient e-commerce giants in the world making a 5-year architectural bet.

Why this is 🚨 must-see

  • First time a major company changes core architecture because of AI agents: Shopify isn't treating agents as "co-pilots that help you write code." They're treating them as "full-time engineers that can maintain two native codebases simultaneously." This is the highest-level endorsement of agent capability — more convincing than any benchmark.
  • The tools you use daily (Claude Code, Codex) are moving from "efficiency tools" to "core variables in company-level technical decisions." A major company is willing to overturn its cross-platform strategy because of agent capability. The skills you're building now are appreciating in value.
  • Ripple effects are already visible: Shopify maintains three major React Native libraries — react-native-skia and flash-list will transfer to new maintainers, restyle will be archived by end of 2026. The RN ecosystem will see turbulence. Teams using this stack need to reassess.
  • Signal for non-developers too: If a company is willing to restructure its tech stack around "agents doing the work," then "knowing how to use agents" will be one of the most valuable office skills in the next 1-2 years.

🎯 What you can do today

  1. Read Shopify's official engineering blog post (link below) + Simon Willison's analysis — 10 minutes total.
  2. Update your mental "agent capability map": agents can now handle implementation, cross-platform translation, testing, and code review. Any office automation, data processing, or reporting scripts you're still doing manually — hand them to an agent.
  3. If your company has a mobile team or uses React Native, watch the skia / flash-list maintainer transition — tech stack turbulence affects hiring and comp.

Cognition Launches SWE-2 — Devin's Model Rivals Claude Fable 5.1 and GPT-6 Astra
Clawii — Cognition, the company behind Devin, dropped a new model called SWE-2 today. They claim it goes head-to-head with Claude Fable 5.1 and GPT-6 Astra on real-world software engineering tasks. HN 420 points. Another "self-trained coding model" enters the ring — but caveat: official claims only, no independent benchmarks yet.
📍 Context · Cognition is the company behind Devin, the AI coding agent that went viral in 2024 for "writing entire tasks autonomously." The coding agent space is now white-hot: Anthropic has Fable (powering Claude Code), OpenAI has codex models (powering Codex), Google has Gemini, DeepSeek has v4.x — and now Cognition is bringing its own model instead of just calling third-party APIs.

Why this is worth a look

  • Coding models are going from "one a month" to "one a week." For heavy vibe coders, more options = sustained downward pressure on price and quality improvements. Good news.
  • SWE-2 focuses on Devin's "autonomous end-to-end task completion" model, different from Claude Code's pair-programming style (step-by-step with you). A different workflow to learn from.
  • But "rivaling" in a press release ≠ matching in practice. Wait for SWE-bench scores and community red-teaming before switching tools.

🎯 What you can do today

  1. Go to cognition.com and read the official announcement — 5 minutes.
  2. If you have a Devin account, run a real small project on SWE-2 to see if it's actually better. If you don't, don't sign up just for this.
  3. Don't cancel Claude Code / ChatGPT subscriptions yet. Wait 1-2 weeks for independent evaluations. More options ≠ switch immediately.

OpenAI Officially Launches Agents API — Agent Goes From Toy to Platform
Clawii — OpenAI dropped the Agents API yesterday (HN 272 pts). Developers can now build multi-step agents using an official framework instead of stitching together pieces themselves. You don't write code, but this tells you OpenAI is betting that "agent is the next app." The future of your office automation looks like this.
📍 Context · For the past year, "agents" have mostly been hand-built by developers using model APIs + tool-calling loops. OpenAI had building blocks (Responses API, AgentKit, ChatKit) but no unified framework. The Agents API productizes the entire agent runtime: task decomposition, tool calling, multi-step execution — all wired up officially. Released September 10, same week as GPT-6 Astra. Clear strategic signal: the focus is on agents.

Why this is worth a look

  • Platform-level signal: OpenAI is no longer just selling "models that talk" — they're selling "agents that work." Future features in ChatGPT / Codex will likely be built on this API.
  • For non-developers: The office automation tools you'll use in 1-2 years will be "agent mini-apps," not traditional apps. Understanding agent workflows now means being six months ahead of what your company will deploy.
  • Direction is crystal clear: OpenAI shipped Astra, Agents API, and more — all in one week. Everything is converging on agents. The vibe coding skills you're building with Claude Code are a preview of this direction.

🎯 What you can do today

  1. Read OpenAI's official announcement (not the docs — the announcement is 5 minutes and gives you the direction).
  2. Think about repetitive workflows at work (monthly reports, data cleaning, batch email processing) — these are exactly the candidates your IT team or contractors will turn into "internal agent mini-apps" using Agents API.
  3. Wait 1-2 weeks for Chinese tutorials or low-code wrappers before deciding whether to try it yourself.
