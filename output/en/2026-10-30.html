Fake Claude Code extension with a backdoor showed up in the Cursor marketplace

A VS Code extension pretending to be Claude Code in Cursor's extension marketplace was reported to have a backdoor. If you installed it, check right now.

Why it matters

  • The HN thread is blowing up, almost 500 comments
  • It pretends to be a tool you use every day, so it's the easiest to fall for
  • A backdoored extension can read the files and keys on your computer

🎯 What you can do

  1. Open the extension list in Cursor/VS Code and check that the Claude Code publisher is Anthropic
  2. If you're not sure, uninstall it and install through the official command line instead
🔬 Deep dive (tap to open)

If you mostly use the command-line version of Claude Code, your risk is lower. But if you installed an extension with the same name in Cursor, you need to check.

The source only has the title and how hot it is on HN, so read the original for how people got hit and how far it spread.
