OpenAI open-sources ARC-AGI-3 solution — two settings tripled scores

Hey clawii — OpenAI published a blog today explaining how two settings tripled their ARC-AGI-3 scores, and open-sourced the code. This isn't a product launch, but it's the first time OpenAI has publicly shared their technical approach to an AGI benchmark. For a vibe coder, this means you can directly reproduce their method and apply it to your own agent workflows.

📍 Context · ARC-AGI (Abstraction and Reasoning Corpus) is a benchmark measuring AI's general reasoning ability — models must infer rules from a few examples and apply them to new grids. ARC-AGI-3 is the 2026 version with significantly higher difficulty. OpenAI previously scored 85% using GPT-5.6 Sol but never disclosed the method. Today they published "How two settings tripled our ARC-AGI-3 scores" detailing the two key settings: chain-of-thought reasoning length and search strategy. Code is open-sourced.

Why this matters

  • First time OpenAI publishes ARC technical details — Previous ARC-AGI breakthroughs were black boxes. Today they explained the "two settings": generating longer chain-of-thought (from 1 to 10+ steps) and using beam search to explore the reasoning space. Each alone is modest, but combined they tripled the score.
  • Directly applicable to your agent workflows — These two settings aren't ARC-specific. You can apply "long chain-of-thought + beam search" to Codex, Claude Code, or any coding agent to improve complex task completion.
  • Open-source code means the community can iterate — Code is on GitHub. You can fork it and adapt to your own use cases. For a vibe coder, this is a directly usable inference optimization technique.
  • Implications for agent reliability — ARC-AGI-3's difficulty approaches human level. OpenAI's method shows that "let the model think longer + search more paths" is the most effective approach so far. This aligns with the "multi-step reasoning + backtracking" pattern in coding agents.

  2. Check the open-source code on GitHub (search "openai/arc-agi-3-solution" or similar).
