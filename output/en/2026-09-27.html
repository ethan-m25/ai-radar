Drawgent: A coding agent that draws on a live Excalidraw canvas

Hey clawii — ever seen a coding agent draw diagrams on a whiteboard while it writes code? Drawgent does exactly that: it puts Claude Code–style coding ability onto an Excalidraw canvas, so you watch it sketch architecture diagrams, edit code, and give feedback in real time.

📍 Context · Coding agents (Claude Code, Codex, Cursor) are already powerful, but their interaction model has always been "you type → it outputs text." Drawgent upgrades the interaction from text to visuals: the agent draws, writes code, and annotates on a live whiteboard. You can drag, edit, and keep the conversation going. It's like going from a terminal to Figma.

Why this matters

  • Visual feedback loop: You no longer have to imagine what the agent is doing — it draws architecture diagrams, flowcharts, and UI sketches right in front of you. You circle what you want changed directly on the board.
  • Non-developer friendly: You don't need to type a prompt like "draw a user login flow diagram" — the agent just draws it, and you drag things around to tweak it.
  • Feels like collaboration: It's no longer "you ask, it answers" — it's two people (you and the agent) drawing together on the same whiteboard.
🎯 Things you can do today
  1. Open the Drawgent demo page and watch it draw on Excalidraw.
  2. If it clicks, clone the Reladraw repo (the diagram language Drawgent uses under the hood) and run it locally.
  3. Think about which "drawing + coding" scenarios in your daily work could use this — system architecture diagrams, prototypes, documentation with illustrations.

ℹ️ FYI

Jev: A new kind of "decision model" — not a chat model

Hey clawii — every AI you've used so far is a "chat model": you ask, it generates text. Jev is something else: it doesn't generate text at all. It outputs numbers — scores, classifications, confidence levels. Built for decisions, not conversations.

Why this matters

  • A new category is born: TypeSafe AI calls Jev a "System One model" (Maggie Appleton suggests "decision model" is a better name). It takes text input but outputs floating-point numbers — e.g. "probability this email is spam: 0.97."
  • Cheaper and faster than an LLM: Because it doesn't generate text, inference costs are much lower. Perfect for classification, scoring, routing, moderation — any scenario where you need a judgment, not an essay.
  • Simon Willison wrote 983 words about it: He says "Jev introduces a new shape of LLM." That's a strong signal from a trusted practitioner.
Jargon decoder · System One model = named after human "system 1" thinking (fast, intuitive, automatic), as opposed to an LLM's "system 2" (slow, reasoning, generative). Jev is system 1; ChatGPT is system 2. · Decision model = a model that outputs numerical judgments instead of generated text.
