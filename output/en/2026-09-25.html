Claude Code 3.0 — the agentic coding era just got a native MCP store

hey clawii — if you vibe-code with Claude Code every day, this is the update you've been waiting for. 3.0 ships with a native MCP store, a computer-use agent mode, and a 40% cheaper Opus-class model under the hood.

📍 Context

Anthropic shipped Claude Code 3.0 yesterday, Sep 24 — the first major version bump in over a year. The 2.x line added subagents and parallel tool calls, but 3.0 lands with three big bets: a one-command MCP store, a browser-controlling computer-use mode, and Opus 4.5, a new flagship scoring 82% on SWE-bench Verified. The coding-agent community has been in overdrive since the announcement.

Why this matters

  • Native MCP store — one command installs 500+ tool integrations (GitHub, Notion, browser-use, spreadsheets) straight from the CLI. No more hunting for config files.
  • Computer-use mode — Claude Code can now drive a real browser end-to-end: book travel, fill forms, check dashboards. The office-drone tasks you hate are now a one-liner.
  • 40% cheaper — Opus 4.5 under the hood at $15/M input vs $25/M for Opus 4.1. Your daily vibe-coding sessions just got meaningfully cheaper.
  • 10 parallel subagents — 3.0 spins up a swarm for code review, test-writing, and docs without blocking your main thread.
