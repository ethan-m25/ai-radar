Hy4-preview: Tencent Open-Sources 770B MoE — HN 312 pts + Simon Willison Tests It
Hey clawii — Tencent's Hy4 hit #8 on Hacker News today (312 points, 192 comments), and Simon Willison just published a hands-on review. 770B total / 49B active, 1M context, Apache 2.0. Perfect weekend reading.
📍 Context · Hy4-preview is Tencent's latest open-weight MoE model. It quietly landed on HuggingFace on August 24, but the Western community only caught on today. Simon Willison posted a detailed review late on August 29, testing it with his "pelican riding a bicycle" prompt and noting the interesting reasoning traces. The model is text-only (no vision), but claims strong benchmark performance across coding and reasoning.

Why this matters

  • HN breakout + KOL review: 312 points on HN is real community signal. Simon's independent test is the cherry on top — the English-speaking world is just now discovering this model.
  • 1M context + Apache 2.0: Commercially friendly license, genuinely useful long-context window.
  • Interesting reasoning traces: Simon noticed Hy4's reasoning uses truncated English (dropping articles like "the", "a"), suggesting the model was optimized for reasoning token efficiency.
  • Only two reasoning levels: "high" (default) and "no_think" — simple and direct.

🎯 Action you can take today

  1. Read Simon's review: simonwillison.net
  2. Check the model on HuggingFace: tencent/Hy4-preview
  3. Try it via OpenRouter (Simon's setup): openrouter.ai, select Hy4-preview — cost should be very low.

vs what you already know: You're familiar with GLM-5.3 and DeepSeek V4. Hy4's active params (49B) are larger than GLM-5.3 (40B), but total params are also larger. Inference speed depends on active params, so Hy4 should be faster than a dense 770B model but slower than Qwen3.8-Flash-Next (6B active). The catch: Hy4 is text-only. If you need vision, pick GLM-5.3 or Qwen.

How hard to use: Weights are 1.56TB in FP16 — local deployment is impractical for almost everyone. Use API providers (OpenRouter, Together, etc.) or cloud inference. If you have an A100 cluster, vLLM supports it. For vibe coding, just hit the API.

Honest caveat: Simon said "still exploring" — not fully stable yet. No vision is a real limitation. But for text and code tasks, it's worth a spin.

GLM-5.3 (753B) Full Weights Go Live on HuggingFace, Top Trending
Hey clawii — Z.ai just dropped the full GLM-5.3 weights (753B total / 40B active, 1M context, MIT license). 50k+ downloads in one day, trending #1 on HuggingFace. Bigger than the Flash version, and it supports multimodal natively.
📍 Context · Last week (Aug 24–27) we tracked GLM-5.3-Flash (321B / 18B active). Today Z.ai released the full GLM-5.3: 753B total / 40B active, MIT license, full weights on HuggingFace. This is more than double the Flash version's size and adds native multimodal (image + text). Artificial Analysis Intelligence Index scores it at 57, close to Claude Opus 4.8 (59). Too big to run locally, but the MIT license means you can use it commercially, fine-tune it, self-host — no strings attached.
GLM-5.3 753B total / 40B active
GLM-5.3-Flash 321B total / 18B active
Hy4-preview 770B total / 49B active
Qwen3.8-27B 27B (Dense)

Why this matters

  • Full weights + MIT: Unlike the Flash version, this is the complete 753B model under the most permissive license. No commercial restrictions, no API lock-in.
  • Native multimodal: Handles images and text directly — unlike Hy4 which is text-only.
  • 1M context window: Whole books, entire codebases. Great for agents and long-document analysis.
  • 50k downloads in one day on HF: Community is voting with downloads.

🎯 Action you can take today

  1. Check the full weights on HuggingFace: zai-org/GLM-5.3
  2. If you can't run 753B locally, start with the Flash variant (18B active, ~12GB VRAM in 4-bit): GLM-5.3-Flash
  3. Watch Z.ai's API pricing — rumored to be excellent value.
