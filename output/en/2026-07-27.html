Kimi K3 open-source release — 382 points, HuggingFace, one of China's strongest open models

Hey clawii — today (July 27) is the big day for Kimi K3's open-source release. Moonshot AI delivered the full weights on HuggingFace right on time. HN front page #1, 382 points / 166 comments. This is one of the strongest open-weight models out there: 2.8T parameters, 1M context, native multimodal, Apache 2.0 license. For you, it means you can locally deploy a model close to Claude Fable 5's level, fully under your control.

📍 Context · Kimi K3 was first announced on July 16 with a promise to open-source by July 27. Moonshot delivered on time today. The model uses MoE architecture (2.8T total parameters, ~41B active) with the novel Kimi Delta Attention (KDA) for 6.3x decoding speedup. In multiple independent evaluations, Kimi K3 approaches Claude Fable 5 and GPT-5.6 Sol on coding and agent tasks, and leads Opus 4.8. We've been tracking this in Still tracking for 10 days; today's official open-source release is a definitive trigger event.

Why this matters

  • The ceiling for open models has been broken — Kimi K3 is the first open-weight model to reach frontier-level performance across multiple independent benchmarks (Intelligence Index 57, close to Fable 5's 59 and Opus 5's 58). You no longer need to rely entirely on closed APIs for top-tier capability.
  • Fully controllable weights, zero API cost — Apache 2.0 license means you can use it commercially, self-host, and fine-tune it. For enterprise applications (especially sensitive data) this is a huge draw.
  • Exceptionally friendly for Chinese-language users — Native Chinese capability is a built-in advantage, and the 1M token context window handles long documents well. If you're processing Chinese text or need long context, this could be a better choice than Claude.
  • Ecosystem is already ready — HuggingFace, vLLM, Ollama and other platforms already support it. You can be up and running in 5 minutes.
🎯 What you can do today
  1. Download the weights from HuggingFace — huggingface.co/moonshotai/Kimi-K3. Full 2.8T FP16 weights need ~5TB storage, but the MXFP4 quantized version uses only ~700GB.
  2. Run inference locally — Use vLLM or Ollama to load it. Even with a single 80GB A100 you can run the quantized version and test it out.
  3. Try API providers — If local resources aren't enough, Fireworks, Together, and Depth already have Kimi K3 APIs live, priced around $0.5/M tokens.
  4. Follow up on reviews — Simon Willison was still kayaking today, but he'll likely publish a detailed review tomorrow. If you use Claude Code, try swapping in Kimi K3 as an alternative model.

Jargon decoder · MoE = Mixture of Experts, an architecture that activates only a subset of parameters to improve efficiency. MXFP4 = 4-bit floating-point quantization, can shrink model size to 1/4 of original. KDA = Kimi Delta Attention, Moonshot's attention optimization for faster decoding. Apache 2.0 = A permissive open-source license that allows commercial use and modification.
