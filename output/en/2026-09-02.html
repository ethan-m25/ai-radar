Simon Willison Finds: ChatGPT/Codex App Bundles Full LibreOffice Copy
Hey clawii — Simon was poking around his ~/.cache folder and found something wild: the OpenAI Codex (now ChatGPT) desktop app ships with 1.7GB of stuff, including a full LibreOffice install, Python, Node.js, and more. Explains how Codex handles document tasks.
📍 Context · The Codex/ChatGPT desktop app is OpenAI's agent tool for coding and document work. People knew it could run code, but nobody knew exactly what was under the hood. Simon's discovery reveals a key architectural fact: OpenAI bundled the entire open-source LibreOffice suite so the agent can natively handle .docx, .pptx, .pdf and other document formats without relying on external services. This is a real "how the sausage is made" moment for agent architecture.

Why this matters

  • Explains Codex's document handling: You've used it to process documents, right? It can edit, convert, and generate formats not because the LLM is magic, but because LibreOffice is doing the actual work behind the scenes.
  • More useful for non-developers: This means Codex/ChatGPT desktop is a real agent for document work — it runs a full office suite locally, not just AI-generated text.
  • LibreOffice is open-source: OpenAI didn't reinvent the wheel — they integrated existing open-source tools. This might be a general pattern for AI agent architecture: using open-source tools to fill the model's blind spots.
  • HN 424 points, 193 comments: Community is fascinated — discussion around performance, security, and what this means for future agent design.

🎯 Action you can take today

  1. Open your ChatGPT/Codex desktop app and check ~/.cache/codex-runtimes/codex-primary-runtime/ for the LibreOffice binaries.
  2. If you haven't used Codex for document work, try asking it to edit a .docx file or convert formats — now you know there's a full LibreOffice under the hood.
  3. Read Simon's original post: The ChatGPT/Codex app bundles a full copy of LibreOffice

vs pure-LLM approach: If you just ask an LLM to generate a document, you get messy formatting and broken layouts. LibreOffice provides a real document engine — the AI just calls the API, LibreOffice handles rendering and conversion.

What it runs on: Codex/ChatGPT desktop app, macOS (Simon's machine). Lives in ~/.cache/codex-runtimes/codex-primary-runtime/.

How hard to use: Zero effort — it's already on your machine. The value is in understanding what your agent can actually do.

Honest caveat: 1.7GB is a lot of disk space. And efficiency of the LibreOffice integration still needs more testing.

🔭 Watch for · Whether other AI apps (Claude Code, Cline, etc.) adopt similar bundling strategies. If this becomes standard agent architecture, the capability frontier expands fast.
