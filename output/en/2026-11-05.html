Vercel lets agents hunt for bugs in code

Vercel's agent scanned its own code around the clock, found 6,817 vulnerabilities, and fixed 1,411 of them. Free until November 10, so worth trying on that little AI-built tool of yours.

Why it matters

  • Finds issues and hands you patches, 1,411 already fixed
  • The free window only lasts until November 10
  • Catches the common bugs in AI-generated code

🎯 What you can do

  1. Look for Security Reviews in the Vercel console, free before 11-10, and point it at a small GitHub project
🔬 Deep dive (tap to open)

It uses an agent to read the code and actually open the app to poke at it, hunting for places someone could break in.

Best for small web tools you vibe-coded; no use for Godot game projects.

The numbers are Vercel's own, so use the free version to see for yourself and don't treat it as foolproof insurance.
