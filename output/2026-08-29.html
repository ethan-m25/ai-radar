GLM-5.3 正式开源权重（HN 708 分）
clawii，Z.ai 把完整版 GLM-5.3（753B）和 Flash 版（321B）一起开源了。HN 上冲到 708 分，235 条评论。虽然模型大得本地跑不动，但 API 便宜，MIT 协议，你想怎么用都行。
📍 背景 · GLM 系列是中国 Z.ai（智谱）的旗舰模型。之前已有 GLM-5.2、GLM-5.3-Flash 发布，但 GLM-5.3 全量权重 今天正式在 HuggingFace 开放，采用 MIT 协议。规格：753B 总参数 / 40B 激活参数，1M 上下文窗口，支持多模态。同时开放的还有 GLM-5.3-Flash（321B/18B 激活）。这是中国开源模型阵营在重量级上的又一次出手。
GLM-5.3 753B 总 / 40B 激活
GLM-5.3-Flash 321B 总 / 18B 激活
DeepSeek V4-Flash 304B 总 / 37B 激活
Qwen3.8-Flash-Next 125B 总 / 6B 激活

为什么这事重要

  • MIT 协议 + 完整权重：你可以自由下载、微调、商用，不限制于 API。
  • 性能对标 Claude Opus 4.8：在编码 benchmark 上宣称平起平坐，AI 分析指数 57（与 Opus 4.8 的 59 接近）。
  • 1M 上下文：处理整本书、整个代码库都不是问题，适合 agent 和长文档分析。
  • HN 708 分不是闹着玩的：社区用脚投票，说明这确实是个里程碑。

🎯 今天就能做的事

  1. 去 HuggingFace 看权重：zai-org/GLM-5.3 和 GLM-5.3-Flash。
  2. 如果本地跑不动 753B，先试 Flash 版本（18B 激活，24GB 显存能跑 4-bit）。
  3. 如果你用 API，去 Z.ai 官网看价格，据说性价比极高。

vs 已有工具：你原来可能用 GPT-5.6 Sol 或 Claude Opus 4.8，它们都是闭源 API。GLM-5.3 开源且 MIT，你可以自部署，数据不出自己服务器。但 753B 需要至少 4 张 A100 才能在 FP16 下运行，4-bit 量化后大约 150GB 显存，普通开发者只能租云。

上手难度：用 vLLM 或 llama.cpp 推理，有现成 docker 镜像。15 分钟能跑起来。但建议先用 Flash 版本。

诚实警告：虽然在 coding benchmark 上接近 Opus 4.8，但真实使用中可能会有差距。而且中文社区可能很快深度评测，到时候看。

👀 值得看
Qwen3.8-Flash-Next：Qwen4 架构预览模型发布
clawii，阿里云发了 Qwen3.8-Flash-Next，这是 Qwen4 的架构预览。125B 总参 / 6B 激活，Simon Willison 已经评测过，说“值得关注”。HF 趋势榜 #2。
📍 背景 · Qwen 系列是阿里巴巴的开源模型家族。Qwen3.8-Flash-Next 是 Qwen3.8 系列的新成员，主打 低激活参数 + 高效果。6B 激活意味着你可以在消费级显卡上跑（RTX 3090 就能 4-bit 量化），同时性能接近 DeepSeek V4-Pro。它是 Qwen4 架构的“预告片”，多模态 MoE。

为什么这事重要

  • 6B 激活 = 本地可跑：这是你真正能在自己的电脑上用的模型，不需要云。
  • 架构前瞻：Qwen4 的新架构（MoE 改进、注意力机制优化）可能会成为下一代开源模型的标准。
  • Simon Willison 亲自评测：他用 DGX Spark 跑了量化版，生成了一些图片（骑自行车的鹈鹕），体验正面。
  • Apache 2.0 协议：商用友好，和 GLM 的 MIT 一样宽松。

🎯 今天就能做的事

  1. 下载 Unsloth 量化版：unsloth/Qwen3.8-Flash-Next-GGUF
  2. 用 Ollama（如果已支持）或 llama.cpp 本地运行：llama-cli -m qwen3.8-flash-next-Q4_K_M.gguf -p "你好"
  3. 看看 Simon Willison 的评测博客：simonwillison.net

vs Qwen3.8-27B：Flash-Next 用 MoE 把激活参数压到 6B，理论上速度快 4-5 倍，同时保留类似质量。但 MoE 的缺点是对 batch 大小不敏感，单次推理可能略慢。

上手难度：5 分钟。下载 GGUF，用 Ollama 或 llama.cpp 直接跑。如果你有 8GB+ 显存，4-bit 量化完全足够。

诚实警告：Simon 提到“仍在探索”，模型可能不稳定。且早期用户报告过 KV cache BF16 问题，官方已经修复。另外，6B 激活的模型在复杂推理上肯定不如 40B 激活的 GLM-5.3，但日常编码和问答绰绰有余。
