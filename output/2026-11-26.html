GPT-6.2 额度消耗变快

它是什么

OpenAI 的 GPT-6.2 有 Astra（旗舰款）和 Sol（日常款）两个模型。发布时计费算错，给大多数用户多打了折，同样的活扣的额度偏少。OpenAI 现已改正：同样的活会多扣额度，用满额度比上周快 Astra 40%、Sol 25%。

意味着什么

如果你用 Codex 跑 GPT-6.2，额度会比上周掉得更快。但官方称仍比 6 Astra 和 6.1 Sol 更耐用。

🎯 怎么用

  1. Go、Plus、Pro、Business 套餐的用户会各多得一次「banked reset」（额度重置），到账方式官方推文没说。
  2. 如果你最近发现 Codex 额度见底变快，原因就在这次修正，不是你用法变了。
🔬 深扒（点开看）

OpenAI 说其他模型不受影响，也不会向你追收过去多用的差额。

OpenAI 的发布页称 GPT-6.2 用更少的输出就能完成同样任务，所以这次涨价后额度表现仍可能比旧版好。

40% 和 25% 是和上周的对比，不是和旧模型比。具体你的额度能撑多久，要看自己的用量。

Karpathy：让 Claude 连跑 7 小时

它是什么

Karpathy 让 Claude 做一张「文明」游戏风格的美国地图，用真实数据填充。Claude Opus 5.5 自己下载并整理了 31 个公开数据源（人口普查、劳工统计等），花 7 小时写了 4.5 万行代码。结果是一个能在网页上浏览的游戏化地图：GDP 对应金币，城市的产业对应区域。

意味着什么

不会写代码的人也能用 AI 做出数据量很大的作品，不过得有耐心，还要消耗大量额度。

🎯 怎么用

  1. 打开 https://karpathy.ai/usaciv/ 随便点点城市和州，看看数据怎么变成游戏语言。
  2. 想研究做法，可以下载页面上的 usaciv-source.zip（MIT 开源许可）。
🔬 深扒（点开看）

Karpathy 用的是 Claude Code 桌面版，Opus 5.5 选「medium」档并打开 ultracode。你平时用的 Claude Code 也能这样跑长任务。

他说这花掉了他一半的每周 Claude 额度，所以长时间自动运行成本不低。

Claude 自己决定跳过几个州和领地。数据由 AI 整理，细节未必都核对过，只能当作有趣的演示。

Astra 22 分钟查出匿名画册作者

它是什么

历史教授 Mark Humphries 只给了很少提示，让 GPT-6.2 Astra 查一本耶鲁 Beinecke 图书馆收藏的 1808 年匿名画册是谁画的。Astra 自己用公开史料检索，22 分钟就找到作者线索。它还在纸质档案里挖出一份很少人知道的资料，这份资料本身也是重要发现。

意味着什么

AI 现在能自己做研究式的侦查，不只是回答问题。对你日常工作影响不大，但值得知道它能做到这一步。

🔬 深扒（点开看）

Astra 先在日记里发现一位子爵 Chabot 到访的记录，时间比画册提到的日期早五天，再推测他的旅行日记能证明画册是他画的，查证后果然如此。

这是教授本人的案例报告，由 Simon Willison 转载，不是严格的实验。

Humphries 认为历史学家受到的冲击会比数学家轻，因为历史写作要靠人的解读。
