编码 Agent 三国杀开打：Meta 低价入局、DeepSeek 登顶、Anthropic 默认为自动

本周 8 条新信号，信号密度中等但质量很高。三条平行故事线都在指向同一个方向：企业 AI 编码正在从「能不能用」进入「怎么算账、怎么安全地用」的新阶段。Databricks 发布了第一套企业级成本核算框架，直接回答 CFO 最关心的问题；DeepSeek V4 Flash 用 1/10 的价格逼近闭源旗舰；Muse Code 以极低价格掀桌子。

🏆 本周最重要的唯一一件事

AI 编码进入「算账时代」：从凭感觉好用，到用数据说服老板

如果你每天在用 Claude Code 或 Codex 写代码，你肯定被问过这个问题：「这玩意儿到底值不值？」以前你可以说「效率提高了」，但现在 CFO 要的是数字。

本周 Databricks 发布的《Managing AI Coding Costs at Scale》是第一套完整的企业级 AI 编码成本核算框架。它把成本拆成三个维度：开发成本（写代码的 token）、调试成本（agent 自我修复的 token）、维护成本（理解遗留代码的 token）。每个 PR 都能算出 token 成本/节省的开发人时。这不是理论——Databricks 自己在用，Accenture 在评论区爆料非工程师才是 token 消耗大户。

与此同时，三条价格线在同步下探：Meta Muse Code 以贡献者价格 $0.10/$0.20 入场，比 GPT-5.6 Luna 还便宜 50%；DeepSeek V4 Flash 以 $0.08/百万 token 的价格登顶 ARC Prize，证明小模型也能做复杂推理；OpenAI 此前也刚刚大幅降价。这不是巧合——模型性价比大战正在重塑整个市场。

Anthropic 本周确认 Claude Code 将在 8 月 14 日默认开启自动模式，安全评估显示自动模式比人类更可靠（人类拒绝危险操作仅 13.6%，自动模式阻止 89%）。这意味着你的编码工具正在变得更安全、更自动，但同时也意味着你在「让出控制权」——你需要信任 AI 自己做决定。

如果本周只做一件事：下载 Databricks 的成本核算 SQL 模板，在你公司跑一次。看看你们团队的 token 都花在哪里了。你可能会发现非工程师的 token 消耗比你想象的高得多——这是你跟老板聊预算的最佳起点。然后，打开 Claude Code 的自动模式试试，感受一下「不用每次点确认」的开发体验。

📈 正在成形的趋势

三条在本周被确认或加速的方向

① 模型性价比大战进入白热化：小模型逼近闭源旗舰

DeepSeek V4 Flash 0731（13B 激活参数，$0.08/百万 token）在 ARC Prize 上达到 64.6%，超过 GPT-5.6 Sol（55.2%）和 Claude 4 Opus（58.1%）。Meta 的 Muse Code 以 $0.10 贡献者价格入局，直接对标 Claude Code 和 Codex。本周的共识很明确：价格不再是选择模型的唯一标准，性价比才是。

② 企业级 AI 编码从「能不能用」进入「怎么算账」

Databricks 的成本框架不是孤例。本周 Qwen3.8-Max 发布时社区的第一反应是「价格多少」，Cloudflare OS 发布时 HN 讨论集中在定价。企业采购 AI 编码工具的关键决策因素正在从「能力对比」转向「ROI 计算」。如果你在公司推广 AI 编码，现在就需要一套成本核算模型。

③ Agent 自动模式成为默认选项

Anthropic 默认开启 Claude Code 自动模式，安全评估反而更强。这与上周 qm 框架（YAML 配置 agent 团队）的趋势一致——AI 工具正在从「需要人工审批的助手」变成「可以自主执行的操作系统」。对人类干预的新定义正在形成：不是每个操作都要确认，而是在关键决策上保留控制权。
