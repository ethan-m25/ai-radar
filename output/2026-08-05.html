Stateless MCP：Simon Willison 重新点燃兴趣

爪哩，Simon Willison 今天发了一篇文章，说 Stateless MCP 重新点燃了他对 MCP 协议的兴趣。HN 上 245 分，125 条评论。MCP 是你可能知道的模型上下文协议，但 Stateless 版本去掉了状态管理，让集成更简单。如果你在用 MCP 服务器或者想自己搭，这个方向值得看。

📍 背景 · MCP（Model Context Protocol）是 Anthropic 推出的开放协议，让 AI 应用可以安全地连接外部工具和数据源。传统 MCP 需要维护状态（比如会话、连接池），增加了复杂度。Stateless MCP 去掉了这些，每个请求独立，类似 REST API。Simon Willison 是 MCP 的早期布道者，他的态度变化往往意味着技术方向在变。

为什么这事重要

  • 降低 MCP 使用门槛 — Stateless 意味着你不需要管理连接状态，写一个简单的 HTTP 处理函数就能当 MCP 服务器用。对 vibe coding 用户来说，更容易自己搭工具。
  • Simon Willison 背书 — 他是 MCP 生态的核心人物，他的"重新点燃兴趣"通常意味着有实质性的改进。他可能会推出相关工具或教程。
  • HN 社区热议 — 245 分 + 125 条评论，说明开发者群体在认真讨论。可能成为 MCP 的下一个主流模式。
  • 对你的意义 — 如果你在用 Claude Code 或 Codex 连接外部工具（比如数据库、API），Stateless MCP 可能让配置更简单，减少出错的概率。

LLM 0.32 发布：推理痕迹 + OpenAI Responses API

爪哩，Simon Willison 今天还发布了 LLM 0.32，这是他那个命令行 AI 工具的重大更新。新版本支持显示模型的推理痕迹（就是模型思考过程），接入了 OpenAI 最新的 Responses API，还增加了服务端工具支持。如果你用 LLM 来管理各种模型，这个版本值得升级。

📍 背景 · LLM 是 Simon Willison 开发的开源命令行工具，可以让你在终端里调用各种大模型（OpenAI、Anthropic、本地模型等）。它支持插件系统，可以扩展功能。很多开发者用它来快速测试模型、写脚本、做自动化。0.32 版本是自项目启动以来最重大的更新之一。

为什么这事重要

  • 推理痕迹支持 — 现在你可以看到模型"思考"的过程，对调试 prompt 和理解模型行为非常有帮助。Claude Code 和 Codex 也有类似功能，但 LLM 让你在命令行里也能看到。
  • OpenAI Responses API — OpenAI 新推出的 Responses API 统一了聊天、工具调用、文件处理等能力。LLM 0.32 原生支持，让你可以用一条命令体验最新 API。
  • 服务端工具 — 允许 MCP 工具在服务端运行，而不是客户端。这对远程部署和团队协作有用。
  • 更好的日志 — 重新设计了 SQLite 日志，内容可寻址，方便回溯和调试。
🎯 今天就能做的事
  1. 升级 LLM：pip install -U llm
  2. 尝试推理痕迹：llm -m gpt-5.6-sol "解释一下量子纠缠" --reasoning（如果模型支持）
  3. 体验 Responses API：llm -m gpt-5.6-sol "写一首诗" --response-api
  4. 阅读 Simon 的发布博客：New release of LLM adds support for reasoning traces, OpenAI Responses, server-side tools, and smarter logging

老实说：LLM 是一个小众但强大的工具，如果你已经用 Claude Code 或 Codex，可能不会每天用 LLM。但 LLM 的优势在于它不绑定任何编辑器，可以在任何终端里用，适合写脚本和自动化。推理痕迹功能尤其有用，因为其他工具不一定能直接显示。
