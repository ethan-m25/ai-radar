🏆 本周最重要的 1 件事

这周没有一个大模型发布，值得你改变工作流。真正改变你工作方式的，是三起「工具背叛」事件。 周二，Postman 被曝偷偷装 AI 插件、还想把全部接口数据发出去（HN 1333 分）；周四，你天天用的 Claude Code 被曝会把你账号邮箱带给它访问的每个网站（HN 1227 分）；到了周日，安全公司 apiiro 直接点名你习惯点的「别再问」——一次放行变成长期授权，1,122 个公开 GitHub 文件里躺着明文密码（HN 434，本周唯一的 🚨）。

三件事串起来，是同一个转向：AI 编码工具从「帮你写东西」，变成「替你碰你的账号、你的仓库、你的密钥」。clawii，你每天处理的恰恰是薪酬、员工数据这种最不能外流的东西。以前你担心的是「模型会不会编错」，这周开始得担心「它会不会把我卖出去」。这不是模型能力问题，是权限边界问题——而边界默认是松的。

和模型新闻比，这条更冷、更不性感，但它决定你能不能安心把真实工作交给它。模型再强，一次误放行就能让整个仓库的密钥见光。所以本周最该记住的不是「谁又发了新模型」，而是「我到底给了这些工具多大权限」。

👉 如果你这周只做一件事：打开 Claude Code 的权限放行列表，把不必要的「别再问」收回来，再对常用仓库跑一遍密钥扫描。十几分钟，值得。

📈 趋势构建

💻本地小模型：从「能跑」走向「能装」

LiquidAI 的 LFM3 家族连续四天挂在 HF 趋势榜（1.7B 版 60.7k 下载、GGUF 版 19.4 万，还新增了 Omni-2B 多模态）；同期「直接读写模型权重」的 Astra 虽被指夸大，但 Simon 用笔记本上的 Qwen 3.8 27B 真的复现了。方向一致：能力在往你自己的电脑上搬。对 clawii 的意义很实在——敏感薪酬文件可以本地处理、断网、不出门。唯一短板：到现在还没有一个非开发者点两下就能用的成品，这是下周该盯的缺口。

🔍AI 写的代码，开始自己查漏洞

Vercel 的 agent 24 小时在自己代码里扫出 6,817 个漏洞、修了 1,411 个，11 月 10 日前免费——这是本周最该白嫖的窗口。周末 Karpathy 又用 Claude Code 三分钟搭了个视频站。一端是「生成越来越快」，另一端是「验证越来越自动」。对 vibe coding 的人，这意味着「写完就交」的风险，正被工具自己接住一部分；但别把它当保险，尤其处理内部工具时。

💸省钱不再靠「选便宜模型」，而靠「自动路由」

Hightouch 的 Jev 遇难题再升级到 Opus，准确率不掉、成本低 4 倍（HN 502）；Gemini Omni 1.2 Flash 主打更快更便宜；OpenAI 和 Anthropic 两边都上了「订阅送等额 API 额度」。信号是：成本控制进到了「让系统自己决定什么时候用贵的」这层。对天天跑批量脚本的你，这是能实打实省下来的钱——以后可以更放肆地让 AI 多试几次。

💀 本周判断失误 / 过热

⚠️ Astra 权重读写：周二当成「新物种」，周三被打回原形

周二我把它说成「今年最像新物种的一步」，理由是 HN 2755 分、能直接改写 Qwen 权重提升能力。周三就被 995 分的质疑拆穿——那其实是篇博客、不是论文，宣传夸大；真正落地的只是 Simon 能在笔记本 Qwen 27B 上本地复现。方向值得盯，但当周热度应从 👀 降为 ℹ️「研究玩具」。教训：这类「重磅突破」先等一周，通常会被打回原形。

⚠️ Claude 个人理财：给 👀 太早，它对 clawii 没有入口

周四给了 👀，理由是「问一句就懂自己的钱」。但它只在美国灰度，Pro 以上、有美国账户才能用；连续跟踪到周日也没有扩区。对不在美国的你，它这周的实际价值是零，应降为 ℹ️ 记个名字，等它出海再说。

⚠️ LFM3 家族：热度真实，但不是「可用」

连追四天，下载和点赞都在涨，这点没错。但四天过去，始终没有非开发者能直接用的成品——我一度把「榜单热度」当成了「你能上手的程度」。不是判错，是优先级该往下压：等 LM Studio、Dify、Ollama 出模板再升级。
