🚨 必看
GPT-6 Astra 发布——OpenAI 的 Fable 竞品到了，安全能力夸张但 ARC-AGI 有隐藏条件
clawii，OpenAI 昨天悄悄发布了 GPT-6 Astra——定价和 Fable 一模一样（$10/$50 每百万 token），但安全测试成绩炸裂：ExploitBench 100%，ExploitGym 42.4%（Sol 才 30.3%）。HN 1856 分，1651 条评论。不过 ARC-AGI 那个 99.9% 有猫腻——用了自研的 Provider Adapter 才拿到。Simon Willison 已经第一时间评测了，说这是 "clearly OpenAI's Fable competitor"。
📍 背景 · GPT-6 Astra 是 OpenAI 对标 Anthropic Claude Fable 5.1 的旗舰模型。定价相同（$10/$50），同样主打编码 + 知识工作 + 长上下文。但 Astra 有两张王牌：一是网络安全能力爆炸（达到 100% ExploitBench），二是支持最高 1M token 的长上下文窗口。不过，它并不是在所有地方都赢——在 Artificial Analysis 的 Intelligence Index 上只拿到 61，和 GPT-5.6 Sol 持平，低于 Fable 5.1（66）和 Meta Muse Spark 1.3。

为什么这事重要

  • 安全能力独一档：ExploitBench 100%（Sol 78.5%），ExploitGym 42.4%（Sol 30.3%），SRE-Bench 二进制逆向 99.2%（Sol 68.7%）。这说明 Astra 在理解漏洞和利用漏洞上远超任何公开模型。对安全从业者来说这可能是新的"垄断级"工具。
  • 长上下文真正可用了：八针测试在 256K-512K 分数 100%，512K-1M 分数 96.3%。过去 "长上下文" 基本是营销概念，Astra 可能是第一个真正能用 100 万字上下文做事的模型。
  • 定价与 Fable 完全对齐：$10/$50 每百万 token 的输入/输出价格，和 Fable 5.1 一模一样。这意味着 OpenAI 正面和 Anthropic 打价格战。Coding Agent Index 上，Astra 在同等分数下成本不到 Fable 的一半。
  • HN 1856 分 / 1651 条评论：今天 HN 上最热的帖子。社区在激烈争论 "这是否意味着 AGI 近了？" 和 "ARC-AGI 得分有猫腻"。

vs Fable 5.1：Fable 在科学评测（52.6% Terminal-Bench-Science）上领先，Astra 在安全能力上碾压。定价相同，但 Astra 的 Coding Agent Index 在前沿成本上更优。

vs GPT-5.6 Sol：Astra 全面超越 Sol，尤其在安全评测上有质的飞跃。长上下文也是碾压式改善。

ARC-AGI 3 的猫腻：Astra 用 OpenAI 自研的 Provider Adapter harness（保留推理状态 + 压缩协议）获得了 99.9%，但标准 ARC-AGI harness 只有 62.7%。说明这个 99.9% 不是纯粹的"新能力"而是一种系统协同优化。

跑在什么之上：OpenAI API / ChatGPT。模型标签 gpt-6-astra。目前仅对 "限量的组织和未来数天的 Plus/Pro/Business/Enterprise 用户" 开放。

上手难度：如果你有 API 账单，直接调用。ChaitGPT 用户等推送。

诚实警告：安全能力虽然炸裂，但华为背后是巨大的推理成本（ARC-AGI 花了 $19K）。Astra 的推理成本可能非常高。另外 Intelligence Index 不领先 Fable——它可能更适合安全任务，而非通用编码。

术语解码 · Provider Adapter harness = OpenAI 自研的评测框架，允许模型在多次请求之间保留推理状态和压缩信息，不同于标准 ARC-AGI 评测的单次隔离方式 · ExploitBench / ExploitGym = 评测模型作为"攻击者"能力的安全基准 · 八针测试 = 测试模型能从长上下文中检索多个分散信息片段的经典评测。

👀 值得看
Qwen 3.8 27B 在 Cerebras 跑出 1500 tokens/s——本地级部署的推理速度新高度
clawii，Qwen 3.8 27B 在 Cerebras 的 Wafer-Scale Engine 上跑到了 1500 tokens/s——这是目前性能最好的 27B 用户级模型在专用硬件上的速度天花板。HN 575 分，190 条评论。虽然 Cerebras 是专用 AI 芯片，但这标志着 2026 年小模型推理速度正在逼近"本地实时"级别。
📍 背景 · Cerebras 的 CS-3 系统使用 Wafer-Scale Engine（晶圆级芯片），在推理速度上一直领先传统 GPU。Qwen 3.8 27B 是阿里巴巴 Qwen 系列的 2026 年主力模型之一，综合能力接近 GPT-4o 级别但参数量只有 27B。1500 tokens/s 意味着一个 1000 token 的请求在不到 1 秒内就能完成。这还没有用到 GPT-6 Astra 那种动辄 $10-$20 的推理成本。

为什么这事重要

  • 小模型 + 专用硬件的组合正在变现实：1500 tokens/s 意味着绝大多数应用场景（聊天、文档重写、代码补全）体验是"瞬间完成"的。虽然 Cerebras 不是人人用得起的硬件，但这个速度指标告诉市场：延迟天花板已经不存在了。
  • 对未来 vibe coding 的影响：如果你用 Codex / Claude Code 的时候，每次请求都要等 3-5 秒，那 1500 tokens/s 就是"一秒都不用等"，体验接近 GPT-4/4o 的实时对话。Cerebras 正在把这个体验价降到远低于 GPT-6 Astra 的水平。
  • 对 Cloud API 定价的潜在压力：如果 Cerebras 能以极低延迟跑 Qwen 3.8 27B，同时定价低于 OpenAI/Anthropic，那云端推理市场可能会被颠覆。

🎯 今天就能做的事

  1. 如果你有 Cerebras API 访问，试试 Qwen 3.8 27B：cerebras/inference 端点，模型名 qwen-3.8-27b。
  2. 读 Simon Willison 的评测（如果有）；目前 HN 上有讨论：HN #5 讨论帖
  3. 思考你正在用的 AI 工具链中，哪个环节可以通过"近乎实时的延迟"来改善体验——比如实时文档重写、快速代码检查。
  4. 关注 Cerebras 2026 年是否推出消费级 Wafer-Scale 芯片——如果价格降到可接受范围，这可能颠覆本地部署。

vs 传统 GPU：Cerebras 的晶圆级芯片在推理速度上有大约 7-15 倍的提升。但这需要专用硬件和直接的内存带宽优势。

vs 本地部署：Qwen 3.8 27B 的 GGUF 量化版（7.8 GB）在 M4 Max 上大约能跑到 30-40 tokens/s。1500 tokens/s 是本地部署的 40 倍左右。

诚实警告：Cerebras 仍然是企业级硬件，不是个人能消费者负担的。但这个速度指标告诉了市场"小模型推理延迟的物理上限在哪"。如果你的工作流对延迟敏感（比如实时语音对话），这个信号尤其重要。
