🏆 本周最重要的唯一一件事

中国开源模型三连发：本地推理的"iPhone 时刻"

本周中国三大 AI 实验室密集发布了开源模型：8/26 Qwen3.8-Flash-Next（125B/6B 激活，Qwen4 架构预览），8/27 GLM-5.3-Flash（321B/18B 激活，MIT 协议），8/29 GLM-5.3 全量版（753B/40B 激活，MIT 协议），8/30 Tencent Hy4-preview（770B/49B 激活，Apache 2.0）。这不是巧合——这是中国开源模型生态的集体爆发。

对 clawii 来说，这意味着什么？第一，你可以在本地跑出接近 Claude Opus 4.8 和 GPT-5.6 Luna 水平的模型。GLM-5.3-Flash 的 4-bit 量化版只需要 24GB 显存（RTX 4090 或 Mac Studio M5 Ultra 都能跑），编码能力号称对标 Opus 4.8。第二，这些模型全部使用最宽松的开源协议（MIT 或 Apache 2.0），商用零门槛。第三，1M 上下文窗口成为标配——GLM-5.3 和 Hy4-preview 都支持 1M 上下文，意味着你可以把整个代码库或整本书丢给模型处理。

这件事的意义不亚于上周的 OpenRouter 被 Stripe 收购——它改变了你作为 vibe coder 的模型选择格局。以前你只能在"本地跑小模型（质量不够）"和"云端用大模型（花钱、延迟、隐私）"之间二选一。现在你可以本地跑一个质量接近一线闭源模型的 MoE 模型，零延迟、零数据外泄、零 API 费用。Simon Willison 已经用 DGX Spark 跑了 Qwen3.8-Flash-Next 和 Hy4-preview，评测结果正面。

如果本周只做一件事：下载 GLM-5.3-Flash 的 GGUF 量化版（unsloth 已出），用 Ollama 或 llama.cpp 本地跑一下你常用的 2-3 个 vibe coding 任务。如果质量满意，考虑把你的日常工作流从云端 API 切换到本地模型。省下的 API 费用可以用来租更强的云 GPU 做更复杂的任务。

📈 正在成形的趋势

三条在本周被确认或加速的方向

① 中国开源模型从"追赶"进入"并跑"阶段

本周三连发（GLM-5.3 · Qwen3.8-Flash-Next · Hy4-preview）标志着中国开源模型不再只是"便宜替代品"，而是真正能与一线闭源模型竞争的选择。GLM-5.3 的 Artificial Analysis 智能指数 57 分（Opus 4.8 为 59 分），Hy4-preview 的 HN 312 分，Qwen3.8-Flash-Next 的 HF 趋势第一——这些数字说明社区已经认可。对 clawii 来说，这意味着你的模型选择不再受限于"只有 OpenAI 和 Anthropic 能做顶级模型"。下周关注：Karpathy 或 swyx 是否评测这些模型；Ollama 是否正式支持 GLM-5.3-Flash 和 Hy4-preview。

② 模型路由成为 2026 下半年最实际的省钱策略

本周 FT 报道（554 分）和 Simon Willison 的解读确认了一个趋势：Fable 5 太贵，Opus 5 够用，模型路由（routing）成为 2026 下半年最实际的省钱策略。AT&T 已经公开说 40% 的 AI 用量走开源模型，目标 60-70%，成本降 56%，质量只掉 2%。这不是理论，是大公司在真金白银地做。对 clawii 来说，这意味着你应该开始配置路由规则——简单任务用便宜模型（Haiku、Flash），复杂任务才用 Opus / Fable。下周关注：OpenRouter 是否推出更智能的路由功能；Vercel 的路由工具是否降价。

③ 小模型时代正式被社区确认

本周 calv.info 的文章 "Small Models Have Arrived"（HN 663 分，299 条评论）总结了最近小模型的爆发。文章核心论点：小模型（<20B 激活参数）已经达到足以替代大模型完成日常任务的水平。GLM-5.3-Flash（18B 激活）、Qwen3.8-Flash-Next（6B 激活）、Hy4-preview（49B 激活）都是例证。对 clawii 来说，这意味着你可以在消费级硬件上运行接近前沿的模型，无需依赖云 API。下周关注：Ollama 是否正式支持这些新模型；是否有更多 KOL 评测小模型的实际表现。

💀 本周我叫错了 / 过度炒作的信号

2 条被降级，1 条需要坦白承认判断偏乐观

Gemini 3.5 Transcribe（8/28 👀 → 降级为 ℹ️） — 周五我把 Google 的转录模型标为 👀，认为它可能改变转录市场格局。但一周过去了，没有独立评测、没有价格公布、没有企业案例。HN 302 分的热度已经消退。转录是一个成熟市场，Gemini Transcribe 需要更多证据才能证明它比 Whisper 或 Deepgram 更好。降级为 ℹ️。

Nvidia 收购 Hugging Face 的短期影响需要降低预期（8/27 🚨 → 保持 🚨 但降低短期预期） — 周三我把这笔收购标为 🚨，认为它是"开源生态最大的结构性地壳运动"。这个判断在长期维度上仍然正确，但一周过去了，没有任何实质性进展——监管审批尚未启动，HF 官方没有发布任何关于"中立性"的承诺，社区讨论已经从"恐慌"转向"等待"。短期（1-2 个月）内对你的日常工作零影响。保持 🚨 但降低短期预期。

未降级确认 — GLM-5.3 正式开源（🚨，HN 708 分，权重已发布，MIT 协议）、Qwen3.8-Flash-Next（👀，Simon Willison 评测，HF 趋势第一）、Hy4-preview（👀，HN 312 分，Simon Willison 评测）、模型路由时代（🚨，FT 报道 554 分，AT&T 数据验证）——这四条仍按原信号强度跟踪。
