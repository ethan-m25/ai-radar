👀 GPT-5.6 Sol 降价 50%：OpenRouter 宣布最新价格，HN 471 分

价格 · API · 降价
📌 背景

OpenRouter 是 OpenAI 模型的第三方 API 提供商，提供灵活的按需付费调用。今天（8 月 18 日）OpenRouter 宣布 GPT-5.6 Sol 的价格降低 50%，从之前的 $0.20/M input tokens 降至 $0.10/M input tokens。HN 上 471 分，294 条评论，社区反应热烈。这是继上个月 OpenAI 官方将 GPT-5.6 Luna 降价 80% 之后的又一次大幅降价，表明模型价格战正在加剧。

💡 为什么重要
  • 价格直接腰斩：GPT-5.6 Sol 是 OpenAI 最新旗舰模型，降价后 $0.10/M input tokens，相比一个月前便宜了一半。对于重度 API 用户，每月成本可节省数千美元。
  • 价格战信号：DeepSeek V4 Flash 已经以 $0.435/M input tokens 冲击市场，OpenAI 联盟通过 OpenRouter 降价回应，中文模型如 Qwen 和 DeepSeek 也在降价。这意味着“便宜智能”时代加速到来。
  • 对 clawii 的意义：如果你用 OpenRouter 调用 GPT-5.6 Sol 做 vibe coding 或自动化办公，成本直接减半。即使你不直接调用 API，降价也会推动整个生态的产品价格下降。
  • 非开发者也能受益：通过 ChatGPT Plus 订阅用户可能不会直接看到降价，但 API 降价会促使更多开发者构建低成本 AI 应用，最终用户也能获益。
⚡ 行动建议
  1. 检查 OpenRouter 账户：登录 OpenRouter，查看新价格是否已生效。如果使用 GPT-5.6 Sol，现在调用成本降低一半。
  2. 重新评估 API 成本：如果你用 GPT-5.6 Sol 做批量处理或自动化任务，重新计算成本，可能可以扩大使用规模。
  3. 考虑切换模型：如果之前因为价格原因使用 Luna 或其他模型，现在 Sol 降价后性能更好，可以考虑切换。
  4. 关注其他平台降价：OpenRouter 降价后，其他平台（如 Together AI、Fireworks）可能也会跟进，保持关注。
🔍 深度解析

vs OpenAI 官方价格：OpenAI 官方 API 价格目前为 $0.20/M input tokens，OpenRouter 降价后 $0.10/M，比官方便宜 50%。但 OpenRouter 是第三方，可能有一些限制或延迟，但通常对大多数用户来说足够。

降价幅度对比：上个月 GPT-5.6 Luna 降价 80%（从 $0.15 降至 $0.03），这次 Sol 降价 50%，说明 OpenAI 正在全面降价竞争。Sol 作为旗舰模型，性能强于 Luna，降价后性价比更高。

对 clawii 的实际影响：clawii 如果通过 OpenRouter 搭建自己的 AI 助手（如用 Codex 写脚本），成本降低后可以更频繁地调用。例如，之前每天花 $10 的 API 成本，现在只要 $5。

诚实的顾虑：降价可能意味着模型服务质量下降（如优先级降低），但 OpenRouter 目前没有报告此类问题。另外，降价可能促使更多用户使用，导致 API 拥堵。

👀 关注点
  • OpenAI 官方是否会跟进降价？
  • 其他第三方 API 提供商（如 Together AI、Fireworks）是否会跟进降价？
  • 降价后是否会有更多用户涌入，导致 API 延迟增加？
📖 术语卡： M input tokens — 百万输入 token，衡量 API 调用量的单位。1M tokens 大约相当于 75 万英文单词或 30 万中文汉字。
