Claude Opus 5 — 接近 Fable 5 的能力，价格仅一半

爪哩，Anthropic 昨天发布了 Claude Opus 5，一个“thoughtful and proactive”的模型，在 Artificial Analysis 排行榜上甚至超过了 Fable 5。价格和 Opus 4.8 一样，但能力接近 Fable 5 那个级别。如果你平时用 API 做 vibe coding，这个模型能让你用更少的钱做更多事。

📍 背景 · Anthropic 的模型线有 Fable（最强）、Opus（次强）、Sonnet 等。Fable 5 一直是顶级模型，但价格昂贵。Opus 5 是 Opus 系列的最新升级，定位是“接近 Fable 5 的智能，但价格只有一半”。根据系统卡，它在 prompt injection 防御上也大幅提升，几乎不可被注入。Anthropic 还发布了专门的 prompting guide 和工程指南。

为什么这事重要

  • 价格减半，能力不减 — 如果你现在用 Fable 5，换成 Opus 5 能省一半钱，但性能几乎一致。在 Artificial Analysis 上，Opus 5 甚至超过了 Fable 5 的排名。
  • 更安全，不易被 prompt injection — 系统卡显示 Opus 5 是最难被 prompt injection 的模型之一。这对你写 agent 或者自动化脚本来说，意味着更少的意外行为。
  • 主动性强，能自己写工具 — 官方演示中，Opus 5 被要求重构一个 3D 模型，但它没有直接查看图片的方式，于是自己写了一个 CV 管线来提取几何信息。这种主动性对复杂任务非常有帮助。
  • 已在 Claude Code 可用 — 如果你用 Claude Code，可以直接切换到 Opus 5 模型，获得更好的编码 agent 体验。
🎯 今天就能做的事
  1. 打开 Claude Code 或 Anthropic API，设置模型为 claude-opus-5，开始测试。
  2. 如果使用 Codex 或 Cursor，检查是否已支持 Opus 5（通常很快会集成）。
  3. 阅读 Anthropic 发布的 Opus 5 提示词指南，了解如何最大化它的能力。
  4. 比较你的日常任务在 Opus 5 和 Fable 5 上的表现和成本，计算切换后的节省。
