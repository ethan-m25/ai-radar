Claude Opus 5 — 接近 Fable 5 但半价，新亲民战神

爪哩，Anthropic 昨天发了 Opus 5，定位是"接近 Fable 5 只要一半价格"——Artificial Analysis 排行榜当前 #1，超过 Fable 5。如果你被 Fable 5 的账单压得喘不过气，这可能是你的新主力。

📍 背景 · Anthropic 的模型家族分 Mythos（最强）、Fable（性价比旗舰）、Opus（主力亲民线）。过去 Opus 系列（如 Opus 4.8）性能明显落后 Fable。这次 Opus 5 直接跳级，逼近 Fable 5 且定价不变——甚至提供了"快速模式"翻倍价格但更快。Anthropic 同时预告了 Opus 5.5，暗示这条线还会继续拉近差距。

为什么这事重要

  • 半价拿 90%+ 效果 — Fable 5 贵得让 vibe coder 肉疼。Opus 5 定价跟 Opus 4.8 一样，但性能接近 Fable 5，意味着你可以省一半的钱或者把 token 预算翻倍。
  • 当前 AI 排行榜 #1 — 在 Artificial Analysis 上排第一，比 Fable 5 还高。首批用户说它"最不易被提示注入"，对 agent 场景是加分项。
  • 主动型行为令人印象深刻 — 官方举了个例子：给了一个机械零件手绘图，模型自己写了计算机视觉管线提取几何信息然后重建 3D FreeCAD 模型。这种主动拆解问题的能力对 vibe coding 很实用。

  2. 对比一下你当前的 Fable 5 调用改成 Opus 5 后质量 & 速度的变化，算算能省多少。
  3. 读 Anthropic 官方发布的 Opus 5 提示指南，看看有没有新玩法：anthropic.com/news

MouthPad — 舌控触摸板，HN 破圈

爪哩，今天 HN 上有个叫 MouthPad 的硬件，用舌头控制触摸板——放在嘴里像牙套一样，靠舌头滑动控制光标。上了 #19 位，19 points，不是 AI 工具，但我觉得对你做 accessibility 或者找自动化硬件的灵感有用。

📍 背景 · MouthPad 由 Augmental 开发，是一个舌控触摸板，像保持器一样放在上颚，通过舌头滑动和点击控制任意蓝牙设备（Mac、iPad、手机等）。产品本身不是 AI 驱动，但作为"非手部交互硬件"，它可以成为 AI agent、vibe coding 等场景的辅助输入设备——比如 hands-free 运行 AI agent 时用舌头微调代码。

为什么这事重要

  • HN 破圈的非 AI 硬件 — 上了 #19，说明 HN 社区对这个产品的创新性认可。即使它不是 AI 工具，"另类输入"本身是一个值得关注的趋势。
  • possibility 与 vibe coding 的结合 — 你 vibe coding 时经常手不够用（一只手咖啡一只手键盘）。MouthPad 如果你愿意折腾，可以当"第三只手"注入 agent 的指令或微调代码。
  • accessibility 的 AI 接口可能 — 如果有 AI 能力加持（如自动补全、语音融合），这类产品可能成为更自然的交互方式。目前是纯硬件，但值得知道名字。
🎯 今天就能做的事
  1. 打开产品页看看它长啥样：augmental.tech — 19 points 不算强信号，但看看概念。
  2. 想一想你自己的 workflow 里有没有"手不够用"的场景——比如你同时运行多个 agent 时，是不是经常切来切去？
  3. 如果觉得有意思，关注一下后续是否有 API 或自动化集成方案——但目前没有。

老实说：这个东西离实用还有距离——舌头控制不如手指精细，你也不太可能每天戴着它 coding。它更是一个"信号"：表明非传统输入设备正在发展，未来可能与 AI 结合。但今天它只是个有趣的硬件玩具，不值得投入时间深度研究。

🔭 关注点 · 关键 trigger event：MouthPad 被 KOL（如 swyx）在 accessibility 场景里讨论，或者 Augmental 发布 SDK 让 agent 可以直接读取 MouthPad 输入。如果没有这些，它就是个有趣但无关紧要的硬件。
