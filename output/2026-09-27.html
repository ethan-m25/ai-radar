Drawgent：在 Excalidraw 白板上实时画图的编码代理

clawii，你见过编码代理一边写代码一边在白板上画图给你看吗？Drawgent 就是这么个东西——它把 Claude Code 之类的编码能力搬到了 Excalidraw 画布上，你看着它画架构图、改代码、实时反馈。

📍 背景 · 编码代理（Claude Code、Codex、Cursor）已经很能干了，但它们的交互方式一直是"你打字→它输出文本"。Drawgent 把交互从文本升级到视觉：代理在一个实时白板上画图、写代码、做标注，你随时可以拖拽、修改、继续对话。这有点像从命令行升级到 Figma 的感觉。

为什么这事重要

  • 视觉反馈闭环：你不再需要脑补代理在做什么——它画架构图、流程图、UI 草图给你看，你直接在白板上圈出要改的地方。
  • 非开发者友好：你不需要写 prompt 描述"画一个用户登录流程图"，代理直接画出来，你拖拽修改就行。
  • 协作感：不再是"你问它答"，而是两个人（你和代理）在同一张白板上一起画东西。

Jev：一种全新的"决策模型"，不是聊天模型

clawii，你用的所有 AI 都是"聊天模型"——你问它答，它生成文字。Jev 是另一种东西：它不生成文字，只输出数字（评分、分类、置信度）。专门用来做决策，不是用来聊天的。

为什么这事重要

  • 新类别诞生：TypeSafe AI 把 Jev 叫做"System One 模型"（Maggie Appleton 建议叫"决策模型"）。它接受文本输入，但输出的是浮点数——比如"这个邮件是垃圾邮件的概率：0.97"。
  • 比 LLM 更便宜、更快：因为不生成文字，推理成本低得多。适合做分类、评分、路由、审核等场景。
  • Simon Willison 专门写了 983 字介绍：他说"Jev 引入了一种新的 LLM 形态"，这是个大信号。
术语解码 · System One 模型 = 类比人类"系统一"思维（快速、直觉、自动），对应 LLM 的"系统二"（慢速、推理、生成）。Jev 是系统一，ChatGPT 是系统二。 · 决策模型 = 不生成文字，只输出数字判断的模型。
