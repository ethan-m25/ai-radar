🚨 Mistral Large 4 — 1T 参数开源模型，Mistral 强势回归

Mistral 官方 · HN 1838 分 · Simon Willison 讨论 · 2026-10-06

clawii，Mistral 回来了！之前大家都以为他们退出了前沿模型竞争，但 Large 4 直接杀回战场：1 万亿参数，490 亿激活参数，性能紧追 DeepSeek V4.1 Flash，而且承诺月底开源。

📍 背景：Mistral 的 Large 3 表现平平，公司重心转向企业定制和主权 AI。很多人以为他们放弃了基础模型竞赛。但 Large 4 证明他们还在。1T 参数 / 49B 激活的 MoE 架构，训练在 3800 块 NVIDIA Grace Blackwell GPU 上。Artificial Analysis 得分 38，仅次于 DeepSeek V4.1 Flash (40)。

为什么这事重要

  • 开源社区多了一个旗舰选择：不再是 DeepSeek 和 GLM 两家独大。Mistral 的开放策略（月底开源）意味着你可以自己跑，也可以找供应商跑。
  • 1T 参数 / 49B 激活的架构：推理成本可以控制得很低，同时保持强大能力。
  • Mistral 的品牌和生态：他们有 Le Chat、Vibe、Studio 等产品，Large 4 会直接提升这些产品的竞争力。

🎯 你现在可以做什么

  1. 去 Mistral API 试玩 preview（目前只支持 API，不支持聊天 UI）。
  2. 关注月底的开源权重发布，到时候 GGUF 量化版应该很快会出来。
  3. 对比 DeepSeek V4.1 Flash 和 GLM-5.3 Flash 的性价比，看看哪个更适合你的场景。

🚨 OpenAI Decisions API — 让 AI 自己做决策的 API，公开 beta

OpenAI 官方 · HN 312 分 · 2026-10-06

clawii，写 agent 最烦的部分就是那个 "决策循环"：什么时候调用工具？什么时候停止？Decisions API 把这个逻辑从你的代码里抽出来，变成了 OpenAI 原生支持的 API。公开 beta 了。

📍 背景：之前构建 AI agent 最大的痛点之一就是状态管理和决策逻辑。你需要自己写复杂的 while 循环、处理上下文、判断下一步。Decisions API 把 "下一步做什么" 的逻辑交给了模型，你只需要定义工具和约束。

为什么这事重要

  • 对 vibe coder 来说：写 agent 的门槛又降低了。你不需要自己写复杂的循环和状态管理。
  • 对企业来说：这是把 AI 从 "聊天机器人" 升级为 "自主执行者" 的关键一步。审批流程、数据分类、邮件自动回复，都可以用 Decisions API 来构建。
  • 开发者社区关注度：312 分 HN，156 条评论，说明大家很关注。

🎯 你现在可以做什么

  1. 阅读 OpenAI 的 Decisions API 文档。
  2. 想一个你日常工作中需要反复决策的场景，试试用 Decisions API 来构建。
🔬 深扒——和你已经知道的工具到底有什么不同

vs 传统函数 calling：传统函数 calling 需要你自己在代码里处理循环和上下文。Decisions API 把 "下一步做什么" 的逻辑交给了模型，你只需要定义工具和约束。

跑在什么之上：GPT-6 Astra 或 GPT-6 Sol。

上手难度：API 调用，5 分钟上手。

你能拿它做什么：构建一个自动处理发票审批的 agent，或者一个自动分类和归档邮件的 agent。

🔭 下一步关注什么

Decisions API 的定价和用量限制。如果价格合理，它会成为构建 AI agent 的标准方式。

👀 OpenAI Ironclad — 让 AI 操控电脑的新能力

OpenAI 官方 · Simon Willison 讨论 Cowork 架构 · 2026-10-06

clawii，电脑操控（Computer Use）是 AI agent 领域最热的方向之一。OpenAI 发布了 Ironclad，Anthropic 的 Cowork 也从本地 VM 迁移到了云端。AI 正在学会像人一样使用电脑。

📍 背景：电脑操控能力让 AI 可以直接操作你的浏览器、桌面应用。Anthropic 的 Cowork 和 OpenAI 的 Operator 都在做。Ironclad 是 OpenAI 最新的电脑操控能力，而 Cowork 的架构变化（本地 VM → 云端）解决了电池、性能和持久化问题。

为什么这事重要

  • 对非开发者来说：这是最直接的 "AI 帮你干活" 的方式。AI 可以直接操作你的浏览器、桌面应用。
  • Cowork 的架构变化：从本地 VM 迁移到云端，解决了电池、性能和持久化问题。现在你可以从手机访问你的 Cowork 会话。
  • Ironclad 是 OpenAI 的官方能力：意味着 ChatGPT 和 Codex 很快就能直接操控电脑。

🎯 你现在可以做什么

  1. 关注 OpenAI 关于 Ironclad 的文档和 API 发布。
  2. 如果使用 Claude Cowork，试试从手机访问你的 Cowork 会话（现在支持云端架构了）。
🔬 深扒——和你已经知道的工具到底有什么不同

vs Anthropic Cowork：OpenAI 的 Ironclad 是 API 能力，Cowork 是产品。两者目标一致，但实现路径不同。Ironclad 更底层，Cowork 更产品化。

跑在什么之上：GPT-6 Astra。

上手难度：API 调用，需要理解 computer use 的 tool calling 格式。

你能拿它做什么：让 AI 帮你填写 web 表单、操作 Excel、在浏览器里做研究。

🔭 下一步关注什么

Ironclad 的公开 API 发布时间。如果 OpenAI 把它集成到 ChatGPT 里，电脑操控会变成主流功能。
