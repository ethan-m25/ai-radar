👀 Mistral Large 4 — 万亿参数模型预览，月底开源

Mistral 官方公告 · HN 1837 分 · Simon Willison 推荐 · 2026-10-06

📍 背景：Mistral 上半年被中国开源模型甩开距离，上次 Mistral Large 3 的 AI 评分只有 9。这次他们带着 1 万亿参数、49B 激活的模型回来了，评分 38，接近 DeepSeek V4.1 Flash。而且承诺月底开放权重。这对于欧洲 AI 生态很重要，也给开发者多一个前沿模型选择。

为什么这事重要

  • Mistral 重回竞争：自从去年 12 月 Mistral Large 3 之后他们几乎从 HN 排名消失，这次是真正的回归。AA 评分 38，证明他们能跟上开源前沿。
  • 开放权重月底：意味着你可以自己跑这个万亿参数模型，或者找其他供应商，不锁定在 Mistral API。
  • 对多语言更友好：Mistral 一直以欧洲语言见长，这对中英之外的用户是利好消息。
🎯 你可以做什么
  1. 立即通过 Mistral API 体验 preview（register.mistral.ai）
  2. 关注月底的开放权重发布，届时可以用 vLLM 或 Ollama 部署
  3. 阅读 Simon Willison 的《Le chonk》博客，了解基准对比

跑在什么之上：Mistral 自有集群（NVIDIA Grace Blackwell），API 目前只通过 Mistral 平台。

上手难度：预览版只需 API key，几分钟上手。开源后需要至少 80GB VRAM（用 4-bit 量化）才能本地跑，普通 Mac 很难。

诚实警告：它不是 Fable 或 Opus 5.5 级别（AA 评分 38 vs 57+），但在同规模模型中表现出色。开放权重才是最大的亮点。

🔭 关注信号：月底开放权重发布时是真正节点。如果 MIT 许可，会有社区量化版本和 Ollama 支持，那时才是你上手的最佳时机。

👀 OpenAI 决策 API 公测 — 让你的 agent 会做“决定”

OpenAI Developers · HN 312 分 · 2026-10-06

📍 背景：之前的 AI agent 只能生成文本，然后靠开发者写逻辑来决策。现在 OpenAI 推出了专门的“决策 API”——模型直接输出结构化的决策，而不是长篇回答。这意味着你可以给 agent 一个审批、分类或选择的任务，它返回“通过 / 拒绝 / 需要更多信息”这类干净的输出。

为什么这事重要

  • 原生决策能力：不再需要提取文字再解析，API 直接返回决策 + 置信度 + 理由。
  • 对 agent 工作流友好：可以轻松集成到自动化 pipeline 中，比如 email 分类、报销审批、路由选择。
  • 降低开发成本：不需要复杂的 prompt engineering 和上下文管理，一个 API call 搞定。
🎯 你可以做什么
  1. 访问 https://developers.openai.com 申请 Decisions API beta 访问
  2. 阅读官方文档，了解如何定义决策 schema
  3. 在 Claude Code 或 Codex 中创建一个测试 agent，把决策 API 当工具调用
🔬 深扒——和普通文本生成有什么本质不同？

普通 API 让模型生成自由文本，你需要自己解析（如正则、关键词匹配）得到“yes/no”。Decisions API 输出一个标准 JSON：{ "decision": "approve", "confidence": 0.92, "reasoning": "..." }。模型在内部使用一个专门的决策头（decision head），训练目标是输出结构化结果，而不是模仿对话。

跑在什么之上：基于 GPT-6 系列模型，但经过额外指令微调。目前只通过 API，没有开源计划。

上手难度：非常低。定义好你的决策 schema（字符串枚举或布尔），然后调用接口。比写 prompt chain 简单得多。

诚实警告：beta 阶段可能有稳差，且仅支持简单的决策场景（二选一或多选）。复杂风险决策仍需人工复核。

🔭 关注信号：正式版推出后的定价。如果每个决策成本低于 0.01 美元，将大规模替代传统规则引擎。另外，观察是否有开源替代（如 Clef 的决策功能）。

ℹ️ EmbeddingGemma 2 — Google 开源开放权重嵌入模型

Google DeepMind 博客 · HN 340 分 · 2026-10-06

一句话：Google 发布了 EmbeddingGemma 2，一个只有 7B 参数但支持文本+图像输入的多模态嵌入模型，采用 Apache 2.0 许可。

为什么这事重要

  • 开放权重 = 长期可用：Simon Willison 专门解释了为什么嵌入模型必须开放权重——商用闭源模型一旦退役，你积攒的百万级 embedding 向量就作废了。EmbeddingGemma 2 让你可以自己跑或者换供应商。
  • 轻量 & 多模态：700M 参数就支持文本和图像，适合小规模检索和 RAG。
  • 业界首个 Apache 2.0 的多模态嵌入模型：其他模型要么闭源，要么许可限制。
