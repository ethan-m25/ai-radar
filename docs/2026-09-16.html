System One Models & Jev — typesafe.ai 的神秘新模型，HN 1456 分

Gemini 3.8 Live & Extended Thinking — Google 实时推理模型上线

Google DeepMind 今天发布了 Gemini 3.8 Live 和 3.8 Live Extended Thinking，支持实时交互和扩展思维链。HN 427 分，278 条评论。

背景：Gemini 3.8 Flash 系列之前已经发布（8 月），主打速度和效率。这次 Live 版本增加了实时语音/视频交互能力，Extended Thinking 则允许模型在回答前进行更长的推理。这是 Google 在 agent 实时交互领域的重要一步，直接对标 OpenAI 的 Realtime API 和 GPT-6 Astra 的实时能力。

为什么这事重要

  • 实时推理是 agent 应用的关键能力——你的 vibe coding agent 如果能实时对话、实时修改代码，效率会大幅提升。
  • Extended Thinking 让模型在复杂任务（如薪酬合规分析）中能“想得更久”，输出更可靠。
  • Google 在实时 AI 上追赶 OpenAI，竞争会带来更便宜、更开放的选项。

🎯 你现在能做什么

  1. 查看 DeepMind 博客：blog.google 搜索 "Gemini 3.8 Live"，了解具体能力和定价。
  2. 在 Google AI Studio 中试用：如果已开放，尝试用实时模式做一个简单的对话或代码审查。
  3. 对比 OpenAI Realtime API：看看 Gemini 3.8 Live 的延迟和价格是否有优势。

🔭 关注什么：未来 1-2 周内是否有第三方 agent 框架（如 LangChain、AutoGPT）集成 Gemini 3.8 Live。如果集成，说明实时 agent 生态开始成熟。

Mistral × Mozilla — 隐私优先的多语言浏览器 AI
