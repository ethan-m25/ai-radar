Gemini 3.8 Flash 发布——又便宜又快，社区直接沸腾（HN 1043 分）
clawii，Google 昨天发了 Gemini 3.8 Flash。Simon Willison 当天就测了：13 秒、1.8 美分，做出一个能跑的网页 demo。这是「便宜 + 够用」路线的最新天花板，跟昨天 Claude Fable 5.1 的「贵 + 更强」正好互补。
📍 背景 · Flash 是 Gemini 家族里「快 + 便宜」的那条线，上一代 3.7 Flash 主要靠速度出圈。这次的 3.8 Flash 是标准升级，但另外发了一个 3.8 Flash Cyber 变体——只对「trusted defenders」（可信防御方，一般指政府/大型安全团队）开放，普通用户暂时摸不到。对非开发者来说，重点在标准版：日常小工具、网页原型、一次性脚本，成本低到可以随便试。

为什么这事重要

  • HN #5、1043 分、581 条评论：今天全站最热的 AI 帖，只比 9/1 的 Claude Fable 5.1（1268 分）低一点。官方发布 + KOL + HN 饱和三信号全齐。
  • Simon Willison 实测：high/medium/low 三档思考模式，13 秒做出一个完整 HTML demo，成本 1.8 美分。他原话是 fast, cheap, and competent——快、便宜、还能打。
  • 生态当天接上：Simon 的 llm 工具已发 0.34 版支持 gemini-3.8-flash，说明 API 当天就能用。
  • 对你的实际意义：想快速做个小工具、网页原型或处理一次性数据，这是一条成本几乎为零的路。重度编码和长链任务，还是留给你熟悉的 Claude Code / Codex。
