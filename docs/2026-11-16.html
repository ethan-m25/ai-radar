Qwen4-Max 发布，HN 热议

它是什么

Qwen4-Max 是阿里巴巴 11 月 16 日正式放出的最强 Qwen 模型，主打复杂专业任务和自主代理（agent，能自己分步骤办事的 AI）。据报道它有 2.4 万亿参数、100 万 token 上下文（一次能读很长的资料），通过阿里云 QwenCloud 和第三方 API 使用。与上一代不同，它不开放权重（不能下载到自己电脑上跑）。

意味着什么

多了一个便宜的新选择，但你已有 Claude Code 和 codex，不必为它换工具。

🔬 深扒（点开看）

阿里称它比 Qwen3.8-Max 少用 35% 的 token，每个任务成本低 60%。这些是厂商自己的说法，我没有找到独立评测验证。

Qwen4-Max 是闭源的，这点和上一代 Qwen3.8-Max（开放权重）不同。阿里说以后会放出较小的 Qwen4 开源模型，但没给日期。

我只查到发布消息，没有核实它写代码的实际表现。HN 上的热度说明很多人在讨论它，不代表它比你现在用的好。

Codex 可能修好了“容量已满”报错

它是什么

用 codex 时常碰到“Selected model is at capacity（所选模型已满载）”的报错：OpenAI 的服务器一时忙不过来，任务就被打断。Codex 团队成员 Thibault Sottiaux 在 X 上说，团队“可能真的修好了”这个问题。这只是一条推文，没有更详细的说明。

意味着什么

如果你常被这个报错打断，现在值得再试一次。但别抱太高期望，以前修过的问题也复发过。

🎯 怎么用

  1. 照常打开 codex 用一段时间，看看报错还出不出现
  2. 报错再出现时，查看 status.openai.com 上的状态公告
🔬 深扒（点开看）

这个报错是服务器端的问题，和你的套餐额度无关。OpenAI 没有给过固定的重试时间。

我搜索时没找到官方宣布“已修复”。OpenAI 状态页和社区论坛里，之前几次“已解决”之后又有用户反映复发。所以这条消息要观察几天再看。

会越用越好的 skill

它是什么

Dan Shipper 所在的 Every 团队在做“会越用越好的 skill”（skill 是一份写好的说明书，任何模型都能加载来照着做）。做法是：保存真实稿件和编辑的修改，把修改意见拆成 74 条“是/否”检查，再让 AI 反复改 skill，直到它的输出过检查。

意味着什么

这套思路你也能用：攒好范例，把判断标准写成是/否检查。不过目前只是一篇实验文章。

🎯 怎么用

  1. 读原文：frontier.every.to 上那篇 Every 的实验记录
  2. 试着用自己的方式：存 5-10 份你满意的成品，把不满意之处写成是/否问题
🔬 深扒（点开看）

Every 的数据：skill 从 v1 迭代到 v9，四个模型得分从 34%–56% 升到约 76%–81%。评分由 Claude Sonnet 5.5 完成，是他们自己的测试，不是独立评测。

这里的“越用越好”不是自动学习，而是人把编辑意见整理成检查，再让 AI 反复优化 skill。工作量主要在攒好范例和写检查题上。

目前没有可直接安装的东西，只有思路和文章。
