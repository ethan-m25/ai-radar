Z.ai 确认 Ox Alpha 为 GLM-5.3 系列，即将开源权重
clawii，过去两周在编码和 agent 基准测试中屠榜的"神秘模型"Ox Alpha 终于被正式认领了——Z.ai（智谱 AI）在 Bloomberg 上确认它是全新的 GLM-5.3 系列模型，并承诺开源权重。这意味着又一个能本地跑、能力接近一线闭源模型的开源选项即将到来。
📍 背景 · Ox Alpha 最早在 8 月中旬以"神秘模型"身份出现在 LMsys 和 Vals 排行榜上，编码和 agentic 任务分数异常高，社区一直猜它是 Z.ai 或 DeepSeek 的新模型。今天 Bloomberg 报道确认了身份：它基于 GLM-5.2 的 743B 参数 base，经过大幅 post-training 优化（包括异步 RL 和 on-policy distillation），能力提升主要来自训练方法和基础设施，而不是单纯的模型规模。Z.ai 明确说权重会开源，但未公布具体时间表。

为什么这事重要

  • 又一个开源模型追平甚至超越一线闭源：Ox Alpha 在编码（Code Arena、SWE-Bench）和 agent 任务上的表现接近 GPT-5.6 Luna 和 Claude Opus 5，但走的是开源路线。你不需要支付 API 费用就能本地跑出接近的质量。
  • 中国开源模型生态持续膨胀：Qwen3.8-27B、DeepSeek V4-Flash、GLM-5.3……中国实验室在开源战略上比美国公司激进得多。Ox Alpha 的加入意味着你作为 vibe coder 的选择越来越多，越来越强。
  • 743B 的 base + post-training 优化：这不是一个"从头训练"的新模型，而是基于 743B 参数的 GLM-5.2 做了大量强化学习优化。它的知识容量很大，但推理成本可能通过蒸馏或 MoE 来降低。
  • 对本地工作流的实际影响：如果 Ox Alpha 的 4-bit 量化版能在 48GB 显存（或 Mac 统一内存）上运行，那你的 vibe coding 后端就可以切换到完全本地、零延迟、零数据外泄的状态。

🎯 今天就能做的事

  1. 关注 Z.ai 的 Hugging Face 组织页，权重发布后第一时间下载。
  2. 检查你的 Ollama 和 vLLM 版本——确保它们支持最新的 GLM 模型格式（ollama list 看当前版本，预计发布后社区会很快适配）。
  3. 在 LMsys 或 Vals 上体验 Ox Alpha 的在线 demo（如果还有的话），感受一下编码和 agent 能力。
  4. 准备好你的本地推理环境：如果你的 Mac 有 48GB+ 统一内存，或者 PC 有 24GB+ 显存，Ox Alpha 的 4-bit 量化版很可能是可跑的。

Ox Alpha 的核心差异化：它不是"更大"，而是"更聪明"。Z.ai 表示，在 GLM-5.2 的 743B 基础上，通过异步 RL（强化学习）和 on-policy distillation（在线策略蒸馏）大幅提升了编码和 agent 任务的能力，而没有增加模型大小。这意味着它可能保留了 743B 的知识容量，但推理成本比原始 dense 模型低得多。

vs Qwen3.8-27B：Qwen 是 27B dense 模型，显存友好（4-bit 约 16GB），但参数规模小得多。Ox Alpha 的 base 是 743B，即使经过蒸馏或 MoE 化，知识容量上的优势是巨大的。Qwen 的优势在于 Apache 2.0 许可和原生多模态。

vs DeepSeek V4-Flash：DeepSeek 是 304B MoE / 37B 激活，已经是开源 MoE 的标杆。Ox Alpha 的 743B base 意味着它在"知识广度"上可能超过 DeepSeek，但具体要看最终发布的架构和激活参数。

跑在什么之上：GLM 系列基于 Transformer，训练用 Z.ai 自研框架。推理可能支持 vLLM、llama.cpp、Ollama（取决于最终发布的格式）。

上手难度：等权重发布后，如果只有原始 PyTorch 权重，需要等社区做 GGUF/MLX 量化，可能需要 3-7 天。如果你熟悉 vLLM，可以直接用原始权重跑。

诚实警告：Z.ai 没有公布具体架构，也没有给出推理的显存需求和时间线。如果它真的是 743B dense 蒸馏到 smaller，可能仍然需要 48GB+ 显存才能跑 4-bit 版本。不要期待它能跑在 8GB 显卡上。

🔭 盯紧什么 · 未来 1-2 周内，关注 Z.ai 的 Hugging Face 页面和 X 账号。如果权重在 7 天内发布，且 Karpathy 或 swyx 发帖说"this is the way"，那就是信号确认。如果延迟超过 2 周，热度可能消退。
术语解码 · GLM = General Language Model（智谱 AI 的通用语言模型系列）· Z.ai = 智谱 AI 的英文品牌名 · Post-training = 预训练完成后的优化阶段，包括 RLHF、蒸馏、量化等 · On-policy distillation = 在线策略蒸馏，模型在推理过程中不断自我优化，把大模型的知识压缩到更小的表示中。
