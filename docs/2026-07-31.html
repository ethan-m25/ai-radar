DeepSeek V4 Flash 更新 — HN 327 points，推理成本降 40%

爪哩，DeepSeek V4 Flash 今天更新了，HN 直接冲到 327 points。核心变化：推理成本降低 40%，支持 1M 上下文窗口，而且 Artificial Analysis 已经出了性能分析。如果你在用 DeepSeek 做 vibe coding 或者跑 agent 任务，这个更新直接省 40% 的钱。

📍 背景 · DeepSeek V4 Flash 是 DeepSeek 的轻量级推理模型，主打低成本、高速度。7/14 AINews 报道了 V4 Flash 的初始版本，但当时没有引起社区关注。今天（7/31）DeepSeek 发布了更新版本，HN 327 points 说明社区注意到了。Artificial Analysis 的独立分析也出来了，提供了性能 vs 价格的详细对比。

为什么这事重要

  • 推理成本降 40% — 对于每天跑大量 agent 任务或 vibe coding 的你来说，这是直接的成本节省。如果你用 DeepSeek API，账单直接少 40%。
  • 1M 上下文窗口 — 这意味着你可以把整个代码库塞进上下文，或者处理超长文档。对于 vibe coding 来说，这解决了"上下文不够用"的痛点。
  • HN 327 points 说明国际社区认可 — 不是 DeepSeek 自己的宣传，是社区自发讨论。Artificial Analysis 的独立分析增加了可信度。
  • 与 Kimi K3 形成竞争 — DeepSeek V4 Flash 和 Kimi K3 都是中国开源模型，但 V4 Flash 更轻量、更便宜，适合个人开发者。

OpenAI GPT-5.6 Luna 降价 80% — Simon Willison 已切换

📍 背景 · GPT-5.6 Luna 是 OpenAI 的轻量级模型，定位是低成本、高速度。7/30 OpenAI 发布了价格更新，Luna 降价 80%，Terra 降价 20%。Simon Willison 7/30 发博文说他把 agent.datasette.io 从 Gemini 3.1 Flash-Lite 切换到了 Luna，因为 Luna 现在更便宜。今天（7/31）HN 尚未出现大规模讨论，但 Simon Willison 的 endorsement 是强信号。

为什么这事重要

  • 价格战信号 — OpenAI 主动降价 80% 说明他们感受到了来自 DeepSeek、Kimi K3 等开源模型的竞争压力。这对用户是好事。
