👀 值得看
Simon Willison 把 ChatGPT Work 讲明白了——"极其混乱但极其强大"
clawii，OpenAI 的 ChatGPT Work 7 月就发布了，但一直没人讲清楚它到底能干嘛。Simon Willison 昨天写了 2,214 字的深度指南，HN 冲到 201 分。你该花半小时读一下。
📍 背景 · ChatGPT Work 是 OpenAI 7 月 9 日发布的 agent 产品，之后一直在快速迭代。它把代码解释器（code interpreter）、Skills、通用 agent（general agents）组合在一起，让 ChatGPT 从"聊天"变成"干活"。但产品本身非常 confusing——Simon 的原话是 "extraordinarily confusing and very powerful"。对不用终端的你来说，这可能是最接近 Claude Code 体验的官方产品。

为什么这事重要

  • Simon Willison 是圈内最靠谱的评测者之一：他花时间把 ChatGPT Work 的机制拆清楚了——你直接抄作业就行，不用自己踩坑。
  • ChatGPT Work 不需要终端、不需要写代码：它是给非开发者用的 agent 入口，正好是你这种 vibe coder 缺的那块拼图。
  • HN 201 分 + 103 条评论：社区也在消化这个产品。你现在读不算晚，等中文圈开始聊就晚了。
  • 它和 Claude Code / codex 是同一类东西，但入口完全不同：理解它 = 理解 OpenAI 的 agent 路线图。

🎯 今天就能做的事

  1. 读 Simon 的原文：Understanding ChatGPT Work（2,214 字，半小时内读完）
  2. 如果你有 ChatGPT 付费账号，打开 Work 模式，试着让它处理一个你平时用 Claude Code 做的任务（比如整理表格、批量改文档）
  3. 去 HN 讨论帖看大家踩过的坑：HN 讨论
  4. 把 Simon 提到的 lethal trifecta（代码解释器 + 文件访问 + 通用 agent 的组合）记下来——这是理解所有 agent 产品的钥匙

vs Claude Code / codex：Claude Code 和 codex 都是终端 / 编辑器里的 agent，面向开发者；ChatGPT Work 是 ChatGPT 原生界面，面向所有人。它内置代码解释器、Skills（可复用的技能包）、通用 agent（能自己规划任务、调用工具）。Simon 用 "lethal trifecta" 形容这三者的组合——合在一起，agent 才能真正干活。

跑在什么之上：GPT-5.6 系列模型，通过 ChatGPT 界面提供，不需要自己搭环境、不需要 API key。

上手难度：有 ChatGPT 账号就能用，5 分钟上手。但"会用"和"用好"差距很大——Simon 写了 2,214 字才讲明白，说明它确实 confusing。

诚实警告：产品还在快速迭代，功能可能随时变。我这边拿到的源只有 Simon 的摘要和 HN 数据，具体功能细节以原文为准。

🔭 盯紧什么 · OpenAI 是否把 ChatGPT Work 的能力开放成 API——如果开放，第三方工具会立刻跟进。另外看 Simon 是否出续篇，以及中文圈什么时候开始聊（那之前你已经有信息差）。
术语解码 · lethal trifecta = Simon 用来形容"代码解释器 + 文件访问 + 通用 agent"这个组合的词——三者合在一起，agent 才能真正干活 · Skills = ChatGPT 里的可复用技能包，类似 Claude 的 Skills · general agents = 通用 agent，能自己规划任务、调用工具、处理长流程。
