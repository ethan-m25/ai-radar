Astra 直接读写模型权重

模型第一次能像改文档一样改自己内部的权重，不用重训。听着吓人，但这是今年最像「新物种」的一步。

为什么重要

  • HN 首页第一，2755 分、837 条评论，全天最热
  • 直接改写 Qwen 的权重来提升能力，跳过训练
  • 你熟悉的 Claude Code 是改代码，这个是改模型本身

🎯 你可以做

  1. 打开下面的演示页，5 分钟能看懂思路，不用装东西
  2. 别急着本地复现，等社区出封装工具更省事
🔬 深扒（点开看）

和 Claude Code 改代码不同：它是直接调模型内部参数（权重），让模型长出原本没有的能力。

跑在 Qwen 这类开源模型上，作者目前只放了演示，没有一键安装的成品。

老实说：现在还是研究玩具，非开发者很难上手；但方向比任何跑分都值得盯。

LiquidAI 一口气开源整个 LFM3 家族

几小时内放出文本、视觉、音频、全模态五个小模型，能跑在自己电脑上，甚至塞进手机。

为什么重要

  • LFM3-1.7B 几小时 4.7 万下载、1310 赞
  • 同时有 GGUF 和 MLX 版本，Mac 上点几下就装好
  • 2B 级别，笔记本离线跑得动，不用调 API

🎯 你可以做

  1. 用 LM Studio 搜 LFM3-1.7B-GGUF，下载后直接聊两句
  2. 拿它试本地文档总结，不花钱、数据不出门
