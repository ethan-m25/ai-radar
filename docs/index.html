小米发布 MiMo v2.6 系列，开源模型性能直逼 GPT-5.6

hey clawii — 小米突然甩出三个开源模型，Flash 版 159B 参数跑分干翻 Llama 3.1 405B，Pro 版更是 524B 参数，而且全部 MIT 协议免费商用。

📍 背景：开源大模型圈已经很久没有「惊喜」了。DeepSeek V4.1 之后，大家都在等下一个能打的开源模型。小米这次直接端出 MiMo v2.6 全家桶：Flash（159B MoE）、Pro（524B MoE）、Distill（9B 蒸馏版）。HN 冲到 #4，927 分，413 条评论，HuggingFace 趋势榜直接屠榜。

为什么这事重要

  • 性能炸裂：MiMo v2.6 Pro 在 MMLU 上达到 89.2%，超过 DeepSeek V4.1 的 88.3%，逼近 GPT-5.6 Sol 的 91%。
  • 开源且免费商用：MIT 协议，你可以直接下载权重，甚至集成到公司内部工具，没有任何法律风险。
  • 蒸馏版 9B 参数：MiMo v2.6 Distill-Qwen-9B 只有 9B 参数，量化后 8GB 显存就能跑，你的 MacBook 也能本地运行。
  • 对你意味着：以后跑本地 AI 助手又多了一个选择，而且性能比同尺寸的 Qwen 3.8 和 Llama 3.2 都强。

🎯 你现在就能做

  1. 去 HuggingFace 搜 XiaomiMiMo/MiMo-V2.6-Flash-RL，下载 GGUF 量化版。
  2. 用 Ollama 跑起来：ollama run mimov2.6-flash（如果 Ollama 已支持）。
  3. 如果你在用 Cline 或 Continue，把模型切到 MiMo v2.6 Distill，体验离线 vibe coding。

跑在什么之上：MoE 架构，Pro 版有 8 个专家，每次激活 2 个。Flash 版更轻量，适合推理。

诚实说：跑分高不代表实际体验好。社区反馈 MiMo 在代码生成上不如 DeepSeek V4.1 稳定，但数学和推理更强。

👀 值得一看

HuggingFace Transformers 原生支持 llama.cpp 量化，本地跑模型再也不用折腾

你看这个 — 以后在 Python 里加载 GGUF 模型不用再装 llama.cpp 了，一行代码搞定，对 vibe coding 用户来说是大福音。

📍 背景：之前想在本地跑开源模型，要么用 Ollama（简单但定制性差），要么用 llama.cpp（强大但需要编译 C++）。HuggingFace Transformers 是 Python 生态的标准库，但一直不支持 GGUF 格式。现在官方直接集成 llama.cpp 的量化内核，你可以在 Transformers 里直接加载 .gguf 文件，就像加载普通模型一样。
中文

为什么这事重要

  • 简化流程：以前加载 GGUF 模型需要 llama.cpp 的 Python binding，现在直接 from transformers import AutoModelForCausalLM 就能用。
  • 性能提升：集成了 llama.cpp 的量化内核，推理速度比纯 PyTorch 快 2-3 倍，显存占用更低。
  • 对 vibe coding 用户：你可以在 Claude Code 或 codex 里调用本地模型做辅助，不用再开两个终端。
  • 生态统一：以后所有 HuggingFace 上的 GGUF 模型都可以直接跑，不用管底层是啥格式。

🎯 你现在就能做

  1. 升级 Transformers：pip install --upgrade transformers（需要 4.48.0 以上）。
  2. 下载一个 GGUF 模型（比如 MiMo v2.6 Distill 的 GGUF 版），然后用 AutoModelForCausalLM.from_pretrained("path/to/model") 加载。
  3. 在你的 vibe coding 脚本里，把 API 调用换成本地模型，体验离线 coding。
🔬 深扒：它和之前的方式有什么不同？
旧方式（llama.cpp）新方式（Transformers 原生）
安装需编译 C++ 或装 pip 包pip install transformers 即可
APIllama.cpp 的 Python API标准 HuggingFace API

速度快（C++ 内核）同样快（底层调用 llama.cpp 内核）

跑在什么之上：Transformers 库内部集成了 llama.cpp 的 GGUF 加载器和量化内核，对用户透明。

上手难度：5 分钟。升级库 + 下载模型 + 一行代码。

诚实说：目前只支持推理，不支持训练。而且有些高级功能（比如 speculative decoding）还没集成。

⚠️ 注意：需要 Transformers 4.48.0+，旧版本不支持。
🔭 下一步看什么：如果接下来一周有更多模型发布 GGUF 格式，并且社区开始用 Transformers 原生加载做 demo，说明这个集成真的落地了。
