Claude Opus 5.5 与 GPT-6 Sol/Luna 发布，AI 价格战正式开打

Anthropic 和 OpenAI 几乎同时放出新模型，性能接近旗舰但价格大幅下降。你 vibe coding 的成本可能直接砍半。

📍 背景 · 过去三周，Anthropic 先后发布 Fable 5.1（9/1）和 Mythos 5.1，OpenAI 则推出 GPT-6 Astra（9/3）。现在双方再次出手：Anthropic 发布 Opus 5.5，性能接近 Fable 5.1 但价格低 40%；OpenAI 发布 GPT-6 Sol（速度优化）和 GPT-6 Luna（成本优化）。Simon Willison 称这是“价格战”，对开发者是重大利好。

为什么这事重要

  • 直接省钱：Opus 5.5 比 Opus 5 便宜 40%，但性能几乎没降。如果你在用 Opus 5，可以无缝切换。
  • 更多选择：GPT-6 Sol 适合需要低延迟的场景（如实时对话），Luna 适合批量任务。你可以按需选模型，不再被单一定价绑死。
  • 对 clawii 的 vibe coding：用 Claude Code 或 Codex 时，可以尝试切换到这些新模型，成本更低，速度更快，迭代更爽。

  2. 在 OpenAI API 中测试 gpt-6-sol 和 gpt-6-luna，对比 Astra 的延迟和价格。

Claude 发现新型酶系统，含 CRISPR 样重复序列

Anthropic 宣布 Claude 在微生物基因组中自主发现了一个全新的酶系统，包含类似 CRISPR 的重复序列。这是 AI 驱动科学发现的重要里程碑。

📍 背景 · 过去一年，AI 在科学领域的应用从辅助分析（如 AlphaFold 预测蛋白质结构）向自主发现演进。这次 Claude 不是被动回答问题，而是主动分析海量基因组数据，识别出从未被记录的酶系统，且包含 CRISPR 样重复序列——这意味着可能开启新的基因编辑工具。

为什么这事重要

  • AI 能力跃迁：Claude 展示了超越“聊天”的推理能力，能独立完成从假设到验证的科学流程。
  • 间接影响：虽然你不能直接用它编辑基因，但这说明模型在复杂模式识别和推理上达到了新高度。这种能力会渗透到其他领域（如法律、金融分析）。
  • 对 clawii 的意义：当你用 Claude Code 处理复杂任务时，底层模型可能变得更可靠、更深入。
🎯 今天就能做的事
  1. 阅读 Anthropic 的官方博客和 HN 讨论，了解具体发现过程。
  2. 不需要立即行动，但可以把这个信号记在心里：AI 正在从“工具”变成“合作者”。

Jev — System One / Decision Models：全新模型类别诞生

TypeSafe AI 发布了 Jev，一种不输出文本、只输出浮点数的模型。Simon Willison 称之为“决策模型”，可能改变我们使用 AI 的方式。

📍 背景 · 传统 LLM 输出自然语言，然后你需要解析它。Jev 直接输出数值（分类、评分、置信度），就像给 AI 装了一个“仪表盘”。它借鉴了丹尼尔·卡尼曼的“系统一/系统二”理论：Jev 是快速、直觉的决策系统，适合分类、路由、审核等任务。

为什么这事重要

  • 新范式：不再需要提示工程来让 LLM 输出 JSON，Jev 原生输出结构化数值，更可靠、更高效。
  • 对 clawii 的潜在用途：可以用来自动分类简历（是否匹配）、评估邮件优先级、给文档打分。不需要写复杂的 prompt。
  • 可能取代部分 LLM 调用：对于只需要“是/否”或“1-5 分”的场景，Jev 比 LLM 更便宜、更确定。
🎯 今天就能做的事
  1. 阅读 Simon Willison 的博客和 Jev 的官方文档，理解其 API 设计。
  2. 如果 API 可用，尝试用 Jev 做一个简单的分类任务（例如：判断一段文本是否与工作相关）。
  3. 关注后续开源实现或替代品。
🔬 深扒——Jev 和普通 LLM 到底有什么区别
维度传统 LLMJev（决策模型）
输出文本（自然语言）浮点数（分类/评分/置信度）
典型任务聊天、写作、代码生成分类、路由、审核、评分
可靠性需要解析，可能格式错误原生结构化，无需解析
成本较高（生成大量 token）较低（只输出几个数字）
可解释性可以通过 chain-of-thought 解释输出置信度，但缺乏推理过程

vs 你已知的：你用过 Claude Code 和 Codex，它们都是生成式 LLM。Jev 完全不同——它不写代码，只做决策。可以把它看作一个“AI 开关”或“AI 评分器”。

跑在什么之上：TypeSafe AI 的云端 API，目前未开源。模型架构细节未公开，但推测是经过专门训练的轻量模型。

上手难度：调用 API 即可，比 LLM 简单（不需要 prompt 工程）。但需要理解你的业务逻辑如何映射到分类/评分。

诚实 caveat：目前只有一家公司在做，生态未建立。如果 TypeSafe AI 被收购或倒闭，你的集成可能作废。建议观望 1-2 周，看是否有开源替代出现。

术语解码 · System One = 来自丹尼尔·卡尼曼的《思考，快与慢》，指快速、直觉的决策系统。这里借用来描述 Jev 的定位。Decision Model = 决策模型，直接输出决策结果而非文本。
