让 Claude 审查你自己的配置

Peter Yang 推荐两条命令，让 Fable 5.2 检查你的 Claude Code 设置并提出修改建议。

为什么重要

  • 新模型出来后，旧的提示词和 skill 可能已经不合适
  • 它会审查 CLAUDE.md、skills 和命令，并给出修复建议
  • 几分钟就能跑完，不用改任何代码

🎯 你可以做

  1. 在 Claude Code 里运行 /doctor prompt-audit，看它提出的修改
  2. 再对最常用的 skill 运行 /claude-api prompt-audit [skill 名]
🔬 深扒（点开看）

这是 Claude Code 里的自检命令，不是新产品。你的规则文件越多，越值得跑一遍。

注意：它只是提出建议，改之前先看一眼，别全部照单接受。

Lovable 应用泄露护照和私信

Lovable 做的应用被曝暴露护照信息和超过 20 万条私信。你自己 vibe code 的东西也该查一下。

为什么重要

  • HN 当天近 900 分，讨论热烈
  • AI 一键做出的应用，权限设置常常没人检查
  • 你做的小工具若放了薪酬等敏感数据，风险一样存在

🎯 你可以做

  1. 回头检查自己做过的小工具：有没有放敏感数据、谁能打开
  2. 让 Claude Code 帮你审一遍访问权限
