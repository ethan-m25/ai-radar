MCP 服务器可自带 skill

它是什么

MCP（Model Context Protocol，让 AI 连接外部工具和数据的统一插口标准）的服务器，现在可以随附自己的 skill（一份教 AI 如何使用的说明书）。Claude Code 装上这个 MCP 后，就自动知道该怎么用它。官方还提到 MCP 将新增 Tasks，用来让 AI 之间更好地协作分工。

意味着什么

以后接外部工具少写提示词、更不容易用错；对你来说是用起来更省心。

🎯 怎么用

  1. 在 Claude Code 里照常添加你需要的 MCP 服务器，看它是否已自带 skill；具体是否支持取决于该服务器作者是否提供。
🔬 深扒（点开看）

以前装了 MCP，Claude 只知道有哪些工具，不一定知道最佳用法，你得自己写说明。现在说明书由工具作者随工具一起提供。

来源只有推文，没说具体的上线版本、支持范围，也没说是否所有套餐都能用。Tasks 的细节同样没展开。

ChatGPT Business 限时免费 fast mode

它是什么

OpenAI Codex 团队成员 Thibault Sottiaux 对 ChatGPT Business（面向团队的付费版）用户宣布两件事：一次“banked reset”，以及到 12 月 31 日前使用 fast mode（更快的响应模式）不额外收费。“banked reset”到底是什么，原推文没有解释。

意味着什么

只有用 ChatGPT Business 的团队才相关；你若是个人用户，基本没有影响。

🔬 深扒（点开看）

“banked reset”可能与用量额度有关，但这只是推测，来源没有确认，请不要当作事实。

fast mode 通常是用更多资源换更快速度，原本可能要另外付费。这次免费到 12 月 31 日，之后是否收费，来源没说。
