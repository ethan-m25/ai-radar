Gemini 推出决策模型 API

Google 新出「决策模型」（专门做是/否、打分这类判断的 AI），还能直接看视频和 PDF。便宜到几乎免费，适合塞进你的小工具。

为什么重要

  • 让 AI 给文档/视频打是/否或分数，比聊天模型更稳
  • 文字、图像、音频、视频、PDF 都能判
  • 和 Jev、OpenAI 同类模型凑成「决策模型」新品类

🎯 你可以做

  1. 读 Simon Willison 的实测，看它怎么判断视频内容（simonwillison.net/tags/ai）
  2. 挑一段你的文件，用一句是/否问题先小样本试准确度
🔬 深扒（点开看）

和你在用的 Claude/codex 不同：它不是聊天，是给固定问题快速打分归类。

文字、图片和 OpenAI 同类；多模态（视频/音频/PDF）是 Gemini 的独门。

门槛低但要走 API，得让 agent 帮你写几行调用。便宜不等于准，先验小样本。

Yogurt：开源的会议笔记

Granola（AI 会议笔记）的开源平替，免费、主打隐私。要记会议又不想把录音传云端，可以看看。

为什么重要

  • 免费开源的会议记录 AI，多一个选择
  • 主打隐私，适合碰薪酬这类敏感内容
  • 可自托管，数据不一定要上云

🎯 你可以做

  1. 去 GitHub 看安装方式（github.com/frigadehq）
  2. 先拿一次内部会议试，别直接上敏感内容
🔬 深扒（点开看）

和你现在用的云端笔记不同：开源、可自己部署，隐私更可控。

只是替代 Granola 的方向，早期项目，转写质量得自己试。

动手门槛中等，可能要 Docker 或本地配置，不是点开就用。
