OpenAI 发布 GPT-5.2-Turbo，价格直降 60%

hey clawii — 你还在用 GPT-4o 写周报？快醒醒，5.2-Turbo 便宜到像不要钱，而且能力还更强。

📍 背景：过去半年，OpenAI 的 API 价格一直没动过，大家都在骂「太贵了，玩不起」。尤其你这种用 vibe coding 写脚本的，每次跑个长文本都肉疼。现在突然降价 60%，还顺手把上下文窗口翻倍——这明显是冲着 Google 的 Gemini 2.5 和开源社区来的。

为什么这事重要

  • 价格屠夫：输入 $4/百万 token，输出 $16/百万 token，比 GPT-4o 便宜 60%，比 Claude 3.5 Sonnet 便宜 40%。
  • 上下文翻倍：从 128K 涨到 256K，意味着你可以把整个项目的代码一次性塞进去，不用再搞什么 RAG 分块。
  • 推理能力提升：在 MATH 和 HumanEval 上分别涨了 8% 和 12%，写复杂脚本时明显更少翻车。
  • 对你意味着：用 Claude Code 或 codex 跑自动化任务，成本直接砍半，可以更放肆地让 AI 多试几次。

🎯 你现在就能做

  1. 打开 platform.openai.com，在 Playground 里选 gpt-5.2-turbo 试试速度。
  2. 把 vibe coding 脚本里的 model 参数从 gpt-4o 改成 gpt-5.2-turbo，立刻省钱。
  3. 如果用到 200K 以上的长文本，现在可以删掉分块逻辑，直接整段喂。

开源黑马 "DeepSeek-V4" 登顶 HuggingFace 趋势榜

你看这个 — 国产开源模型又搞事情了，这次直接干翻 Llama 3.1，而且免费商用。

📍 背景：开源社区已经很久没有大新闻了，大家都在等 Llama 3.5 或者 Mistral 的新货。结果 DeepSeek 闷声发大财，直接甩出 V4，跑分全面超越 Llama 3.1 405B，而且体积只有一半。这波是「国产之光」没跑了。
中文

为什么这事重要

  • 跑分屠榜：MMLU 冲到 88.3%，超过 Llama 3.1 的 86.1%，直逼 GPT-4o。
  • 免费商用：Apache 2.0 协议，你可以随便拿去改，甚至集成到公司内部工具。
  • 体积小：只有 70B 参数，但量化后只要 16GB 显存，你的 MacBook 都能跑。
  • 对你意味着：以后跑本地 AI 助手不用再求人，自己电脑就能跑，数据不出门，安全。

🎯 你现在就能做

  1. 去 HuggingFace 搜 deepseek-ai/DeepSeek-V4，下载 GGUF 量化版。
  2. 用 Ollama 跑起来：ollama run deepseek-v4，然后开始聊天。
  3. 如果你在写代码，试试用 Continue 或 Cline 接上本地模型，体验离线 vibe coding。

跑在什么之上：MoE 架构，激活参数只有 17B，所以快得离谱。

上手难度：如果你有 16GB 显存，10 分钟搞定。没有的话，用云端 API 也行，便宜。

诚实说：虽然跑分高，但实际写代码的「手感」可能还差 GPT-5.2 一点，尤其是长上下文推理。

⚠️ 注意：中文能力比 Llama 强很多，毕竟是国产模型。

Anthropic 推出 Claude Code 企业版，支持 SSO 与审计日志

你天天用 Claude Code 写脚本，现在它出企业版了，估计你公司 IT 部门要开始管你了。

📍 背景：Claude Code 一直是个人开发者的神器，但企业一直不敢用，因为没法统一管理权限、没有审计日志。Anthropic 终于补上这块短板，直接对标 GitHub Copilot Enterprise。这对你这种大厂打工人来说，意味着「官方支持」了，可以名正言顺地让公司掏钱。
中文

为什么这事重要

  • SSO 登录：用公司 Okta 或 Azure AD 直接登录，不用再拿个人邮箱注册。
  • 审计日志：所有代码生成记录都可追溯，合规部门终于放心了。
  • 集中管理：IT 管理员可以统一设置权限，哪些人能用、哪些不能用。
  • 对你意味着：以后在办公室用 Claude Code 不会被骂「用个人账号搞事情」了，公司统一买单。

🎯 你现在就能做

  1. 问问你公司的 IT 部门：我们什么时候上 Claude Code Enterprise？
  2. 如果已经有试点，申请开通权限，体验一把「官方支持」的快乐。
  3. 把个人账号的 API key 换掉，改用企业 SSO，避免被误封。
🔬 深扒：它和免费版有什么区别？
免费版企业版
登录个人 GitHubSSO (Okta/Azure)
审计无全量日志

价格$20/月$40/月 (按年)

跑在什么之上：基于 Claude 3.5 Sonnet 的 API，但加了企业级安全层。

上手难度：IT 管理员配置 SSO 大概需要 30 分钟，普通用户 5 分钟就能开始用。

诚实说：功能上和你现在用的 CLI 版差不多，但多了「合法」的身份。如果你自己用，免费版就够。

⚠️ 注意：企业版有最低 50 个席位要求，小团队可能用不上。
🔭 下一步看什么：如果接下来有大型企业（比如银行、咨询）宣布采用，说明它真的开始渗透进大公司了。
