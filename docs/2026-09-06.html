AI 控制 Blender 做 3D 渲染——Simon Willison 展示新玩法，非开发者也能做 3D
clawii，Simon Willison 今天发了一篇博客：用 ChatGPT Codex 通过自然语言让 Blender 渲染出“骑自行车的鹈鹕”3D 场景。这不仅仅是好玩——它意味着 AI 能直接操纵复杂的 3D 建模软件，而你不必学 Blender 的复杂界面和 Python API。无论你是想做产品渲染图、简易动画，还是把想法变成 3D 视觉，这可能是一条新路。
📍 背景 · Blender 是开源 3D 创作套件，功能强大但学习曲线陡峭。以前要用它做渲染，要么手动建模，要么写 Python 脚本。现在 AI 可以通过自然语言调用 Blender 的命令行或者 Python API，自动生成场景。Simon 演示了在 macOS 上通过 Codex（ChatGPT 的编程代理）直接控制 Blender，效果令人惊讶。

为什么这事值得关注

  • 自然语言驱动 3D 建模：你不再需要学 Blender 的快捷键、材质节点、渲染器设置。只需说“用 Blender 渲染一个骑自行车的鹈鹕，背景是海滩，夕阳”，AI 就能自动执行。Simon 的博客里甚至展示了迭代改进：先加背景，再“做得更好”，最终生成了相当不错的渲染图。
  • 对非开发者友好：你不需要懂 Python 或 Blender 的 API。只要在 Codex 或 Claude Code 里输入自然语言指令，AI 就能调用 Blender 并输出结果。Simon 的提示词是：“Use the already installed /Applications/Blender to render a scene of a pelican riding a bicycle”。
  • 潜在应用广泛：产品原型可视化、展示图、简易动画，甚至可以作为“设计助手”帮你快速迭代想法。对于做产品、营销、个人项目的人，这可能是一个新的生产力工具。
  • 生态扩展信号：这不仅仅是 Blender——它表明 AI 可以控制任何有命令行接口或 API 的复杂软件。未来可能扩展到 CAD、视频编辑、音频处理等。

🎯 今天就能做的事

  1. 如果你有 macOS 并且安装了 Blender（从 blender.org 下载），打开 ChatGPT Codex 或 Claude Code，输入类似 Use the already installed /Applications/Blender to render a scene of a pelican riding a bicycle 试试。
  2. 读 Simon Willison 的完整博客：TIL Using Blender with coding agents on macOS
  3. 尝试更复杂的提示，比如“加背景”、“改变灯光”、“让鹈鹕飞起来”。Simon 展示了迭代提示的效果。
  4. 如果你没有 macOS，可以尝试在 Linux 上安装 Blender 并用类似方法。
🔬 深扒——它是怎么工作的？和传统的 3D 渲染有什么区别？
对比项传统 3D 渲染AI 控制 Blender（Simon 演示）
学习曲线高：需学 Blender 界面、建模、材质、渲染设置极低：只需自然语言提示
控制粒度精细：手动调整每个参数粗粒度：AI 自动决定细节，但可通过迭代提示改进
速度取决于技能：熟练者几分钟，新手几小时几秒到几分钟（AI 推理 + Blender 渲染时间）
可重复性高：可以保存 .blend 文件精确复现低：AI 每次可能生成不同场景，但可以通过固定种子改善
适用场景专业项目、精细控制快速原型、想法可视化、非专业需求

技术原理：Codex（或 Claude Code）通过自然语言理解用户意图，然后调用 Blender 的 Python API（bpy 模块）生成场景。Simon 的提示词直接指定了 Blender 的路径，AI 知道如何启动 Blender 并执行 Python 脚本。这类似于“AI 作为 Blender 的脚本编写器”，但用户不需要写脚本本身。

局限：目前 AI 对复杂场景的控制能力有限，可能无法处理精细的材质或动画。但 Simon 演示的迭代改进表明，通过多次提示可以逐步优化。另外，需要本地安装 Blender（约 500MB），且 AI 需要能够调用系统命令。

诚实警告：这不是新产品，而是现有工具的创意用法。但它的出现表明 AI 正在突破“代码生成”进入“3D 内容生成”领域。对于非开发者来说，这可能是一个值得尝试的“酷玩具”，但短期内不会取代专业 3D 工作流。

🔭 盯紧什么 · 看其他 KOL（如 swyx、Riley Goodside）是否也会尝试类似用法。如果 Blender 的 AI 控制成为趋势，可能会有专门的工具出现（比如“自然语言转 3D 场景”）。另外，关注 OpenAI 或 Anthropic 是否会在 API 层面提供更直接的 3D 生成能力。
术语解码 · Blender = 开源 3D 创作套件，支持建模、渲染、动画、视频编辑等 · bpy = Blender Python API 的模块名，允许通过脚本控制 Blender · Codex = OpenAI 的编程 AI 代理，可以执行代码和系统命令。
