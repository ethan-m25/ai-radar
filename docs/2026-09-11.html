OpenAI Agents API 正式发布 — 官方"造 agent"平台，同天 GPT-Live-1 进 API
clawii，OpenAI 昨天正式发布了 Agents API——官方版的"造 agent 平台"。HN 272 分、151 条评论。同一天还把 GPT-Live-1（实时语音模型）放进了 API。如果你一直在用 Claude Code / codex 做 vibe coding，这个 API 是"从聊天到自动化"的官方路径。
📍 背景 · OpenAI 之前有 Agents SDK（开源代码库）、Responses API、各种内置工具（网页搜索、代码执行等）。Agents API 是把这些整合成一个官方托管服务，让开发者不用自己拼装。对非开发者来说，这意味着"用 OpenAI 造自动化 agent"的门槛在降低。

为什么这事值得看

  • 官方托管：不用自己维护 agent 框架，API 调用就行。对想自动化的非开发者，这是最省事的入口。
  • 生态信号：OpenAI 把 agent 作为一等公民，说明 agent 是平台方向——你学的技能不会白费。
  • GPT-Live-1 进 API：实时语音 agent 的门槛也降低了——以后做语音助手不用自己拼 TTS + LLM + STT。

🎯 今天就能做的事

  1. 读 OpenAI 的 Agents API 官方公告：openai.com/index/introducing-the-agents-api
  2. 读开发者文档：developers.openai.com
  3. 关注定价——如果比 ChatGPT 订阅便宜，可以考虑用它跑自动化任务
  4. 看 HN 讨论了解早期反馈：hn.algolia.com/?q=Agents API

👀 值得看
Shopify 从 React Native 撤回原生 — 因为 AI agent 让双端成本不再是问题
clawii，Shopify 宣布从 React Native 撤回原生（Swift + Kotlin），理由是：AI agent 已经能搞定双端实现的成本。HN 1087 分、778 条评论，Simon Willison 也专门写了分析。这是大公司用真金白银投票：agent 正在改变工程经济学的底层逻辑。
📍 背景 · 2020 年 Shopify 从原生切到 React Native，为了"不用写两遍"。六年后的今天，他们决定切回去。原因不是 React Native 不好，而是 agent 让"写两遍"的成本不再是决定性因素。Simon 的总结："What changed is that agents can now do enough of the implementation, translation, testing, and review work that it's no longer the deciding factor it was in 2020."

为什么这事值得看

  • 大公司架构决策被 agent 改变：这不是 demo，是 Shopify 官方工程博客 + HN 1087 分热帖。
  • 对 vibe coder 的启示：别再为"写一次跑两处"过度优化——agent 可以帮你移植代码。
  • 生态影响：react-native-skia 和 flash-list 要换新家，restyle 年底归档。如果你用 RN 生态，注意这个变化。

🎯 今天就能做的事

  1. 读 Shopify 官方博客：shopify.engineering
  2. 读 Simon Willison 的分析：simonwillison.net/tags/ai/
  3. 想想你自己的项目：有没有因为"跨平台"而选了复杂方案？agent 时代可能不需要了。

诚实警告：这是大公司的特定决策，不代表所有人都该放弃跨平台框架。但"agent 改变工程经济学"这个信号是真实的。
