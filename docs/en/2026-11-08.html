Update: the Claude Code permission trap is leaking passwords

That 'don't ask again' you click every day might let Claude Code send your passwords into a public repo. Take two minutes to check your permission list.

Why it matters

  • Security firm apiiro called out 'don't ask again' — 1,122 public GitHub files contain plaintext passwords
  • If you use Claude Code daily, this is a real account risk
  • Details are in the original; for now, check yourself assuming the worst

🎯 What you can do

  1. Open Claude Code's permission allowlist and revoke any unnecessary one-click approvals
  2. Run a secret scan on your regular repos to make sure no password files got committed
🔬 Deep dive (tap to open)

This isn't a new feature — it's a permissions design trap: one 'don't ask again' can turn into permanent access, so you have to watch it yourself.

Anyone who's handed it a big directory or a repo with secrets in it and clicked one-click approve should check.

The self-check takes about ten minutes; don't wait for an official fix — tightening permissions and scanning for secrets is the safest move.
