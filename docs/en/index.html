MCP servers can ship with a skill

What it is

MCP (Model Context Protocol, a standard plug that lets AI connect to outside tools and data) servers can now come with their own skill (a how-to guide that teaches the AI how to use them). Once you install the MCP in Claude Code, it automatically knows how to use it. The official post also mentions that MCP will get a new Tasks feature, so AIs can split up work and team up better.

What it means

Down the road, you'll write fewer prompts when hooking up outside tools, and it's less likely to get things wrong. Basically, it's less hassle for you.

🎯 How to use it

  1. Add the MCP servers you need in Claude Code like usual and check whether they come with a skill. Whether it works depends on whether the server's author provides one.
🔬 Deep dive (tap to open)

Before, when you installed an MCP, Claude only knew which tools were there, not necessarily the best way to use them, so you had to write the instructions yourself. Now the tool's author ships the guide along with the tool.

The only source is a tweet. It doesn't say which version it launches in, how widely it's supported, or whether every plan gets it. The details on Tasks aren't spelled out either.

ℹ️ FYI

ChatGPT Business gets fast mode free for a limited time

What it is

Thibault Sottiaux, from the OpenAI Codex team, announced two things for ChatGPT Business (the paid plan for teams) users: a "banked reset", and no extra charge for fast mode (a quicker response mode) until December 31. The original tweet doesn't explain what the "banked reset" actually is.

What it means

This only matters for teams on ChatGPT Business. If you're an individual user, it basically doesn't affect you.

🔬 Deep dive (tap to open)

The "banked reset" might have something to do with usage limits, but that's just a guess and the source doesn't confirm it, so don't treat it as fact.

Fast mode usually trades more resources for more speed, and it might have cost extra before. It's free until December 31 this time, but the source doesn't say whether it'll cost anything after that.
