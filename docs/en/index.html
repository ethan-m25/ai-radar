Claude moves whiteboards, tables, and data analysis into the chat

Claude can now open a whiteboard, edit tables, and turn metrics into dashboards and narrated videos right in the conversation—your comp report is saved.

Why it matters

  • Edit tables and whiteboards right in the chat, no more exporting and re-importing
  • Claude Data turns metrics into dashboards and videos with voiceover
  • Open Adobe, Atlassian, and Box full-screen through connectors and edit directly

🎯 What you can do

  1. Find the Sheets and Data entry points on Claude web or desktop (paid tiers start rolling out today)
  2. Check the official notes to see how the new whiteboard, tables, and data analysis work
🔬 Deep dive (tap to open)

Different from what you do now: before, getting Claude to work on a table meant exporting and re-importing; now it edits as you chat, and Whiteboard is good for sketching the structure first, then filling in the numbers.

Data (formerly Dashboards) is clearly built for non-technical people: drop in a set of metrics, and it builds a shareable dashboard, a data story, even a narrated video—that saves a lot of work on quarterly comp reviews.

Easy to try, and paid tiers are already rolling out. Downside: new features ship in batches, so you might get tables today and the rest tomorrow.

👀 Worth a look

Gemini 4 Carbon is open to everyone

Gemini 4 Carbon used to be only for safety folks, and today it's available to all; both Simon Willison and Dan Shipper say it's clearly better at coding.

Why it matters

  • Codes better than Argon, and Dan Shipper says in real tests it can go for hours
  • Global Ultra access in the Gemini App, and /swarm in Antigravity
  • $2/$10 per million tokens now, doubles Dec 1, so try it early

🎯 What you can do

  1. Switch to Gemini 4 Carbon in the Gemini App (Ultra subscription), or try /swarm in Google Antigravity
🔬 Deep dive (tap to open)

Different from the Claude Code/Codex you use: Carbon is Gemini's new flagship, reached through the Gemini App and Antigravity IDE; /swarm splits work across sub-agents, and in Sundar's demo it modeled, wrote a game, and did voiceover on its own.

Easy to get started, and Ultra can use it directly. Downside: Dan Shipper says on long tasks it often "doesn't know when to stop," and Simon's max tier burned through tokens without delivering.

👀 Worth a look

Stop agents from writing 2019 JavaScript

The Chrome team packaged a set of modern web rules; paste them into your coding agent and it'll write less old-school JS and produce cleaner pages.

Why it matters

  • Specifically fixes the agent habit of copying old code and writing old-style JavaScript
  • Made by Paul Irish, set it up once and Claude Code/Codex both benefit

🎯 What you can do

  1. Go to github.com/googlechrome, find this Show HN project, and add it to your agent config as instructed
🔬 Deep dive (tap to open)

Doesn't change which tool you use: it just feeds Claude Code/Codex a "modern web practices" reference so they stop generating old-style code.

Very low cost, just drop it into project rules or a skill. Limit: it only covers frontend web work, not plain scripts or spreadsheet tasks.
