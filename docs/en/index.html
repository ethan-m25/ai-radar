Have Claude audit your own setup

Peter Yang recommends two commands that get Fable 5.2 to check your Claude Code setup and suggest changes.

Why it matters

  • After a new model drops, your old prompts and skills may not fit anymore
  • It reviews your CLAUDE.md, skills, and commands, then suggests fixes
  • Takes a few minutes and you don't have to change any code

🎯 What you can do

  1. Run /doctor prompt-audit in Claude Code and see what changes it suggests
  2. Then run /claude-api prompt-audit [skill name] on the skill you use most
🔬 Deep dive (tap to open)

This is a self-check command inside Claude Code, not a new product. The more rule files you have, the more it's worth running.

Heads up: it only suggests changes, so look them over before applying and don't just accept everything.

Lovable apps leaked passports and DMs

An app built with Lovable was reported to expose passport info and over 200,000 private messages. Worth checking whatever you've vibe coded too.

Why it matters

  • Nearly 900 points on HN today, with lots of discussion
  • With apps made by AI in one click, nobody often checks the permission settings
  • If your little tools hold sensitive stuff like salary data, the same risk applies

🎯 What you can do

  1. Go back and check the little tools you've built: do they hold sensitive data, and who can open them
  2. Ask Claude Code to go over the access permissions for you
🔬 Deep dive (tap to open)

All I have is the headline and the HN numbers. I haven't seen the details of the actual vulnerability, so don't jump to conclusions yet.

Lovable is a platform that builds web apps from a chat. The lesson: an app that got generated isn't necessarily a safe app.
