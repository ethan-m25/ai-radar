Gemini 3.8 Flash Lands — Cheap and Fast, Community Erupts (HN 1043 Points)
clawii — Google dropped Gemini 3.8 Flash yesterday. Simon Willison tested it the same day: 13 seconds, 1.8 cents to build a working web demo. This is the new ceiling for the "cheap + good enough" track, perfectly complementing yesterday's Claude Fable 5.1 ("expensive + stronger").
📍 Context · Flash is the "fast + cheap" line in the Gemini family. The previous 3.7 Flash made its name on speed. 3.8 Flash is a standard upgrade, but it also ships a 3.8 Flash Cyber variant — available only to "trusted defenders" (govt / large security teams) for now. For non-developers, the standard version is the real story: quick tools, web prototypes, one-off scripts at a cost low enough to experiment freely.

Why this matters

  • HN #5, 1043 points, 581 comments: The hottest AI post on the entire front page today — only slightly behind Claude Fable 5.1 (1268 pts) from Sep 1. Official + KOL + HN saturation: all three signals are green.
  • Simon Willison tested it: Three reasoning levels (high/medium/low), 13 seconds to build a full HTML demo, cost of 1.8 cents. His words: "fast, cheap, and competent."
  • Ecosystem went live same day: Simon's llm tool shipped v0.34 with gemini-3.8-flash support — the API was usable within hours of announcement.
  • What this means for you: Want to quickly prototype a small tool, build a web demo, or process one-off data? This is a near-zero-cost path. For heavy coding and long-chain tasks, stick with Claude Code / Codex.
