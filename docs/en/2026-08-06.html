Meta Muse Code + Muse Spark 1.2: open-source coding agent enters the ring

Hey clawii — Meta released Muse Code (beta) and Muse Spark 1.2 today, an open-source coding agent and its companion model. 266 points and 167 comments on HN. Simon Willison also wrote a review. This is Meta formally entering the coding agent competition, going head-to-head with Claude Code and Codex. There's also a unique pricing model — if you let Meta use your data, the price drops by more than 10x.

📍 Context · The coding agent market is currently dominated by Anthropic's Claude Code and OpenAI's Codex. Meta previously had Muse Spark 1.1, but this is the first time they're releasing a dedicated coding agent (Muse Code), co-trained with the model. The key innovation is "harness-model co-design" — the agent and model are optimized together rather than separately. Simon Willison noted in his blog that "the most important characteristic of any model these days is long-sequence agentic tool calling."

Why this matters

  • Open-source coding agent enters the ring — Muse Code is Meta's coding agent, Muse Spark 1.2 is the companion model. Both are co-trained and specifically optimized for long-horizon coding tasks. This gives you a new option alongside Claude Code and Codex.
  • Ultra-low "contributor" pricing — If you agree to let Meta use your data to improve their products, the price is $0.10/$0.20 (input/output per million tokens), cheaper than GPT-5.6 Luna. This may be Meta's way of collecting high-quality coding data.
  • Simon Willison reviewed it — He used Muse Spark 1.2 to generate an SVG of a pelican riding a bicycle and said it's a "small but material improvement" over version 1.1. His reviews usually mean the model is worth a serious look.
  • What it means for you — If you're using Claude Code or Codex for vibe coding, try Muse Code as a complement. Especially if you don't mind Meta using your data, the price advantage is huge.

Cloudflare OS: open agent platform, 567 points on HN

Hey clawii — Cloudflare released Cloudflare OS today, an open platform for agents, apps, and work. 567 points and 274 comments on HN. This isn't an operating system — it's an agent runtime platform where you can deploy and run AI agents using Cloudflare's global network. If you're thinking about agent deployment and hosting, this is worth checking out.

📍 Context · Cloudflare previously had Workers (serverless compute), but Cloudflare OS is a higher-level abstraction specifically designed for agents. It provides the infrastructure agents need: state management, tool calling, security sandboxing, global deployment. Unlike traditional cloud platforms (AWS, GCP), Cloudflare OS is designed from the ground up with agent needs in mind — long-lived connections, tool calling, MCP support.

Why this matters

  • Agent-native platform — Cloudflare OS is the first cloud platform specifically designed for agents. It has built-in infrastructure for everything agents need: state management, tool calling, security sandboxing, global deployment.
  • 567 points on HN — Strong developer interest. The 274 comments include lots of technical discussion comparing it to AWS and GCP.
  • Open ecosystem — Cloudflare emphasizes openness, supporting MCP protocol, multiple models, and multiple programming languages. No lock-in to a specific model or framework.
  • What it means for you — If you're building agents that need deployment (automation workflows, data processing pipelines), Cloudflare OS could be a simpler option than traditional cloud platforms. Especially if you already use Cloudflare's network services.
🎯 What you can do today
  1. Read Cloudflare's official announcement: Cloudflare OS: an open platform for agents, apps, and work
  2. Check the HN discussion: Cloudflare OS (567 points)
  3. Sign up for the Cloudflare OS preview (if available)
  4. Think about your current agent deployment setup: could Cloudflare OS simplify it? Especially if you already have a Cloudflare account.

If you're already using Cloudflare Workers, migrating to Cloudflare OS will be natural. But if you're deeply tied to AWS or GCP, the migration cost may be significant.

Discovery Loop: founded by former Google DeepMind core team

Hey clawii — Discovery Loop hit 772 points on HN today. Even though this is funding/startup news, the founding team is so strong it's worth knowing the name. 483 comments on HN with very active discussion.

Why this matters

  • 772 points on HN — Strong developer interest. 483 comments include lots of discussion about AI for Science.

  • What it means for you — You probably won't use Discovery Loop's products directly, but knowing what this team is working on helps you understand the frontier of AI research.
