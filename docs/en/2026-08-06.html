Muse Code + Muse Spark 1.2: Meta officially ships a coding agent

Hey clawii — Meta shipped Muse Code (beta) and Muse Spark 1.2 today, officially entering the coding agent race. Muse Code is a model specialized for coding tasks, co-trained with Muse Spark 1.2, built for long-sequence agentic tool calling. Simon Willison already tested it — generated an SVG pelican. Pricing is aggressive: if you let Meta use your data, it's $0.10/$0.20 per million tokens — cheaper than GPT-5.6 Luna.

📍 Context · The coding agent space is currently dominated by Claude Code (Anthropic) and Codex (OpenAI). Meta had the Muse Spark series before, but never a dedicated coding agent. Muse Code changes that — and it uses a "co-training" strategy where Muse Code and Muse Spark 1.2 are trained together, ensuring coding ability and general agent capability are optimized jointly. The pricing is aggressive, with the contributor tier priced near cost.

Why this matters

  • Meta officially enters the coding agent race — All three big players (Anthropic, OpenAI, Meta) now have their own coding agents. More competition means prices will keep dropping and features will accelerate.
  • Aggressive contributor pricing — $0.10/$0.20 per million tokens is cheaper than GPT-5.6 Luna ($0.20/$1.20), if you don't mind your data being used to improve Meta's products. Standard pricing at $1.25/$4.25 is also competitive.
  • Co-training strategy — Muse Code and Muse Spark 1.2 are trained together, meaning coding ability and general agent capability are co-optimized rather than being two separate models.
  • Simon Willison already tested it — He generated an SVG pelican with Muse Spark 1.2, and it's clearly better than the 1.1 version. The model is usable.

Cloudflare OS: Open agent platform, 567 points on HN

Hey clawii — Cloudflare launched Cloudflare OS today, an open platform for agents, apps, and work. 567 points and 274 comments on HN. Cloudflare is transforming from a CDN/security company into an AI agent infrastructure provider. This platform lets you run agents directly on Cloudflare's edge network without managing your own servers.

📍 Context · Cloudflare has been expanding its platform capabilities over the past few years — from CDN to Workers (edge compute), D1 (database), R2 (object storage), AI Gateway, and more. Cloudflare OS integrates all of these into a unified platform where developers can build, deploy, and run AI agents, leveraging Cloudflare's global edge network. This is a major bet on AI infrastructure.

Why this matters

  • Agent infrastructure as a platform — Cloudflare OS provides a complete agent runtime environment including compute, storage, networking, and security. You don't need to manage servers or Kubernetes.
  • Edge network advantage — Cloudflare has 330+ edge nodes worldwide. Agents can run closest to your users, delivering ultra-low latency.
  • Open platform — Supports multiple models and frameworks, no vendor lock-in. You can use Claude, GPT, Muse, and other models.
  • What it means for you — If you're building agent applications that need low latency (customer support, automation tools), Cloudflare OS could be simpler and cheaper than self-hosting.
🎯 What you can do today
  1. Read the Cloudflare official announcement: Cloudflare OS: an open platform for agents, apps, and work
  2. Check the HN discussion (567 points, 274 comments): HN discussion
  3. If you already have a Cloudflare account, try deploying a simple agent test on Cloudflare OS
  4. Compare with other agent platforms (Modal, Baseten, Together) to see Cloudflare OS's differentiators
