Tencent Hy4-preview: 770B Open-Source MoE, 1M Context, HN 312 pts
Hey clawii — Tencent open-sourced Hy4-preview, a 770B total / 49B active MoE model with 1M context under Apache 2.0. HN hit 312 points with 192 comments. The Chinese tech press covered it a week ago, but the HN discussion thread is high quality and worth reading this weekend.
📍 Context · The Hy series is Tencent's open-source MoE model line. Hy3 (295B / 21B active) launched in July. Hy4-preview is a major upgrade: 770B total / 49B active, 1M context, 1.56TB of weights. It's text-only for now (no vision) and has two reasoning effort levels: "high" (default) and "no_think". Simon Willison already tested it with his classic "pelican riding a bicycle SVG" prompt and got solid results.
Hy4-preview 770B total / 49B active
Hy3 295B total / 21B active
GLM-5.3 753B total / 40B active
DeepSeek V4-Flash 304B total / 37B active

Why this matters

  • 49B active = runnable locally: 770B total sounds scary, but MoE means only 49B activate per inference. At 4-bit quantization that's ~30GB VRAM — an RTX 4090 can barely handle it.
  • 1M context window: Same as GLM-5.3 — whole books or entire codebases. Great for agents and long-document analysis.
  • Apache 2.0 license: Commercial-friendly, as permissive as MIT.
  • Simon Willison tested it personally: He ran it via OpenRouter and noted the reasoning trace uses truncated English ("Let's maybe add a helmet?") — interesting behavior.
  • HN 312 points is not noise: Community discussion centers on "how does it compare to GLM-5.3" and "why only two reasoning levels."

🎯 Action you can take today

  1. Check the model card on HuggingFace: tencent/Hy4-preview
  2. Try it online via OpenRouter: openrouter.ai/tencent/hy4-preview
  3. Read Simon Willison's review: simonwillison.net
  4. If you have 32GB+ VRAM, grab a GGUF quant and run locally: ollama pull tencent/hy4-preview:q4_K_M (if Ollama already supports it)

vs GLM-5.3: Hy4-preview has more total params (770B vs 753B) and more active params (49B vs 40B), but GLM-5.3 supports multimodal (vision + text) while Hy4 is text-only. Both are MoE, 1M context, open-source. GLM-5.3 uses MIT license, Hy4 uses Apache 2.0 — both are permissive.

How hard to use: If you use OpenRouter, 5 minutes to try. Local run needs at least 32GB VRAM (4-bit quantized). Use vLLM or llama.cpp. Ollama may already support it.

Honest caveat: Simon noted the reasoning trace uses truncated English, suggesting the model optimizes token efficiency during reasoning. Also, only two reasoning levels (high / no_think) — no middle ground. Chinese tech press covered it a week ago, but the HN discussion is high quality.

🔭 Watch for · Whether Karpathy tries it. If he tweets about it, Hy4-preview becomes another milestone for Chinese open models. Also watch for Ollama official support in their model list.
📖 Jargon decoder · MoE = Mixture of Experts — multiple expert sub-networks inside one model, only a subset activates per token · Active parameters = the number of parameters actually used per inference call, determines VRAM and speed · Reasoning effort = controls how many tokens the model spends thinking before answering · Reasoning trace = the intermediate output of the reasoning process, letting you see what the model is "thinking."
