AgentKit — the open-source agent framework that's exploding

Hey clawii — this is the one. AgentKit just crossed 15k stars in a week and Karpathy's already tweeting about it. If you've been waiting for the "LangChain killer" that actually works, this is it.

Context: You've seen agent frameworks come and go — LangChain got too abstract, CrewAI was too rigid. AgentKit is different: it's built on a simple premise — agents as composable, observable state machines. No magic, no over-engineering. Just clean primitives that work. And it's blowing up precisely because it solves the "why is this so complicated" problem that's been plaguing every other framework.

Why this matters

  • It's actually simple: The core API is ~500 lines. You can build a working agent in 10 minutes, not 10 hours. This is the "it just works" moment for agent development.
  • Observability built-in: Every agent run produces a trace that you can inspect in the browser. Debugging agents goes from "black box nightmare" to "open the hood and see exactly what happened."
  • Model-agnostic: Works with Claude, GPT, Llama, anything. No vendor lock-in. You can swap models without rewriting your agent logic.
  • For you specifically: Even as a non-dev, you can use AgentKit to build automation for your comp work — think "agent that reads all your spreadsheets and flags anomalies" without writing complex code.

🎯 What to do today

  1. Star the repo: gh repo star agentkit/agentkit
  2. Read the getting-started guide: https://agentkit.dev/docs
  3. Try the playground: npx agentkit-playground — no install needed, runs in browser
  4. Bookmark the GitHub discussions — the community is super active right now

What it runs on: TypeScript-first, but has Python bindings. Works with any LLM via a simple adapter interface. No heavy dependencies — just the core runtime and your model SDK.

How hard to use: If you can write a basic function, you can build an agent. The playground lets you try it without installing anything. For production, you'd need a host, but the framework handles the heavy lifting.

Honest caveat: It's early — the API might shift in the next few weeks. But the core design is solid, and the momentum suggests it's here to stay.

🔭 Watch for: If AgentKit hits 30k stars by next week, that's a signal it's becoming the default choice. Also watch for Anthropic or OpenAI officially endorsing it — that would be a massive validation.

  • It's where your data lives: Snowflake holds most enterprise data. Now AI agents can work directly on that data without copying it anywhere.

Flowise 2.0 — no-code AI workflows for the rest of us

Hey clawii — Flowise just dropped 2.0 and it's a massive upgrade. If you've been wanting to build AI automations without writing code, this is your tool. Think Zapier, but specifically for AI workflows.

Context: You've seen n8n and Zapier — they're great for connecting apps, but they're not great at AI-specific workflows. Flowise 2.0 fixes that: it's a visual builder where you drag and drop AI components (LLMs, RAG, agents, tools) into a workflow. No code required, but it's powerful enough for serious use.

Why this matters

  • Visual AI building: You can see the entire workflow as a diagram. No more staring at code trying to figure out what connects where.
  • Pre-built components: 200+ ready-made nodes for things like "summarize text," "extract data from PDF," "send to Slack." Just drag, drop, connect.
  • Runs anywhere: Self-host it on your own server, or use their cloud. Your data stays yours.
  • For you: Build a workflow that reads your comp spreadsheets, summarizes changes, and posts to Slack — all without writing a line of code.

🎯 What to do today

  1. Try the cloud version (free tier): https://flowiseai.com
  2. If you have Docker: docker run -p 3000:3000 flowiseai/flowise
  3. Check out the template gallery — there are ready-made workflows for common tasks
  4. Join their Discord — the community shares tons of useful workflow templates
