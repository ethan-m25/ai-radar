Claude Opus 5 — Close to Fable 5 capability at half the price

Hey clawii — Anthropic dropped Claude Opus 5 yesterday, a "thoughtful and proactive" model that's already #1 on the Artificial Analysis leaderboard, ahead of Fable 5. Same price as Opus 4.8, but capability is close to Fable 5 territory. If you use APIs for vibe coding, this model lets you do more for less.

📍 Context · Anthropic's model lineup runs Fable (strongest), Opus (next tier), Sonnet, etc. Fable 5 has been the top-tier model but it's expensive. Opus 5 is the latest upgrade to the Opus line, positioned as "close to Fable 5 intelligence at half the price." According to the system card, it's also the hardest model yet to prompt inject. Anthropic published a dedicated prompting guide and engineering guide alongside the release.

Why this matters

  • Half the price, same ballpark performance — If you're using Fable 5 today, switching to Opus 5 cuts your cost in half with almost no quality drop. On Artificial Analysis, Opus 5 actually ranks above Fable 5. AINews reports it matches Fable 5 on software engineering benchmarks, with an Epoch Capabilities Index of 159 vs Fable 5's 161.
  • Much harder to prompt inject — Boris Cherny from Anthropic says "Opus 5 is our least prompt injectable model yet." If you're building agents or automation scripts, this means fewer unexpected behaviors from malicious inputs.
  • Proactive — it writes its own tools — In one demo, Opus 5 was asked to reconstruct a 3D FreeCAD model from a drawing, but had no direct way to view the image. It responded by writing its own computer vision pipeline to extract geometry from raw pixels, then rebuilt the full machine part. That level of initiative is huge for complex tasks.
  • Available in Claude Code now — If you use Claude Code, you can switch to the Opus 5 model right now for a better coding agent experience.
🎯 What you can do today
  1. Open Claude Code or the Anthropic API, set the model to claude-opus-5, and start testing.
  2. If you use Codex or Cursor, check whether they've integrated Opus 5 yet — integrations usually roll out fast.
  3. Read Anthropic's Opus 5 prompting guide to understand how to get the most out of it.
  4. Compare your daily tasks on Opus 5 vs Fable 5 — measure quality and cost, then calculate your savings if you switch.
