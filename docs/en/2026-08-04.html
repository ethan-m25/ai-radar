Show HN: Run an 80B Qwen in 4.3GB RAM on a Mac, and a 35B on an iPhone

Hey clawii — someone just posted a Show HN that's blowing up: a tool that runs an 80B-parameter Qwen model in just 4.3GB of RAM on a Mac, and a 35B model on an iPhone. 201 points, 88 comments. If this is real, the barrier to local vibe coding just dropped to zero.

📍 Context · Running large models locally has been a hobbyist obsession. llama.cpp and Ollama made 7B-13B models feasible on consumer hardware, but 80B models typically need 48GB+ of VRAM/RAM. 4.3GB implies extreme quantization (maybe 2-bit or even 1.5-bit), and running 35B on an iPhone is unheard of. The tool comes from GitHub user leonickson1. The HN thread is lively — some skepticism, but the author is showing demos.

Why this matters

  • Local 80B model barrier collapses — Previously, running an 80B model required multi-GPU setups or a 64GB+ Mac Studio. Now a regular MacBook (16GB RAM) might be enough. That means you can use top-tier open models completely offline.
  • 35B on an iPhone — If this works on a phone, mobile AI changes completely. Offline translation, local agents, privacy-sensitive tasks — all possible on-device.
  • What it means for you — You vibe-code with Claude Code and Codex. If you can run an 80B open model locally (like Qwen3.6-27B or DeepSeek V4 Flash), you can work fully offline with zero API costs. This tool could be the key.
  • Community heat is real — HN 201 points, 88 comments, active debate. Many asking for open-source release and replication. The author is responding positively.

MiniMax H3 Day-0 ComfyUI support: open video gen with native audio, 2K video

Hey clawii — MiniMax's H3 model just got Day-0 support in ComfyUI, hitting 300 points on HN. It's a 33B-parameter open video generation model with native audio and 2K video output. You're not a video person, but open video models getting this good means AI content creation is rapidly democratizing — useful for demos, training materials, and promo videos for your vibe-coding projects.

📍 Context · MiniMax is a Chinese AI company previously known for text models. H3 is their video generation model: 33B parameters, open weights (MIT license? TBD). ComfyUI is the popular Stable Diffusion workflow tool, and Day-0 support means you can generate video with a node-based interface immediately. The HN post is from comfy.org, 300 points, 87 comments.

Why this matters

  • New bar for open video models — 33B params, 2K video, native audio. This is one of the most capable open video models available. Previous open models (like Stable Video Diffusion) were low-res and audio-free.
  • ComfyUI ecosystem integration — Day-0 support means users can generate video with node-based workflows immediately, no coding required.
  • What it means for you — You can use this to quickly generate demo videos, training materials, or promo content for your vibe-coding projects. Open-source means you can run it locally (with a GPU).
  • Community heat — HN 300 points, 87 comments — the English-speaking community is paying attention.
