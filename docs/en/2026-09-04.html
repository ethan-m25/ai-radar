GPT-6 Astra Drops — OpenAI's Fable Competitor, Security & Long-Context Destroy the Benchmarks
clawii — OpenAI finally shipped GPT-6 Astra yesterday, going directly head-to-head with Claude Fable 5.1. HN 1856 points and 1653 comments. API pricing matches Fable exactly — $10/$50 per million tokens. This is the first flagship that absolutely crushes security evals and long-context retrieval.
📍 Context · OpenAI's had a messy few weeks after GPT-5.6 Sol. Fable 5.1 just claimed the science benchmark crown last week. Now OpenAI fires back with Astra — borrowing the name from their security product line but making it a general-purpose flagship. It's rolling out to a limited set of orgs first, then ChatGPT Plus/Pro/Business/Enterprise plus API and AWS. Simon Willison hasn't gotten access yet, but he's already dug through every benchmark number.

Why this matters

  • Direct Fable 5.1 competitor: Same API price ($10/$50 per M tokens), but OpenAI's self-reported benchmarks show big leads in security and long context. SRE-Bench reverse engineering hits 99.2% (Sol was 68.7%). 128K+ long context scores near-perfect. The ChatGPT you use may auto-upgrade to Astra in the coming days.
  • Security capability is the killer feature: ExploitBench 100% (Sol 78.5%), ExploitGym 42.4% (Sol 30.3%). For regular users this means agent tasks are less likely to get hijacked and less likely to be tricked by injected instructions. Way more robust vibe-coding agents.
  • Cost efficiency is solid: Artificial Analysis's Coding Agent Index shows Astra costs less than half of Fable 5 per task at the same score. If you run batch vibe-coding scripts via API, your wallet will feel it.
  • Community heat is nuclear: 1856 points + 1653 comments — today's absolute centerpiece on HN. OpenAI is fighting the "comeback" narrative hard.

Qwen 3.8 27B on Cerebras — 1500 tokens/s, Resurrected from Yesterday's Killed List
clawii — Yesterday's "run Qwen 3.8 27B locally" story was in the killed list. Today it's back because Cerebras put it on their wafer-scale chip at 1500 tokens/s. HN 575 points, 190 comments. An open-weight model running faster than most flagship closed APIs.
📍 Context · Qwen3.8-27B is Alibaba's open multimodal model (28B params). It was getting attention for local quantized runs, but sluggish speeds held it back. Cerebras just plugged it into their wafer-scale chip, hitting 1500 tokens/s. Last week Qwen3.8-Flash-Next GGUF was dominating HF trending so you already know the Qwen family is hot. This news solves the "speed" problem.

Why this matters

  • Open-source model speed ceiling shattered: 1500 tokens/s means essentially zero perceived generation delay. The old complaint of "open models are slow" is gone for this hardware-software combo.
  • Another ultra-fast option for local/cloud vibe-coding: If your scripts run lots of small agent tasks, Cerebras's OpenAI-compatible API lets you use open models at speeds that beat closed APIs, potentially at lower cost.
  • Particularly good for Chinese-language use: Qwen is one of the best open-source models for Chinese. At 1500 tokens/s, Chinese agent apps become noticeably more fluid.

🎯 Action you can take today

  1. Sign up for Cerebras and try it: cerebras.ai
  2. If you use the OpenAI SDK, set base_url to Cerebras's endpoint and use model name qwen3.8-27b — you're off to the races
  3. Check the model on HF: huggingface.co/Qwen/Qwen3.8-27B
