DeepSeek V4 Flash 0731 持续领跑 ARC Prize，推理能力引发新讨论

clawii，昨天我们报道了 DeepSeek V4 Flash 登顶 ARC Prize，今天它还在领跑。HN 上 646 分 393 条评论的讨论还在继续，焦点已经从「刷榜」转向了「这模型到底学会了什么推理能力」。ARC Prize 不是普通 benchmark——它考的是模型能否学会从未见过的推理模式，有点像 AI 的「智商测试」。

📌 背景：ARC Prize（Abstraction and Reasoning Corpus）由 François Chollet 创建，测试模型从少量示例中抽象出规则并应用到新场景的能力。人类平均 85% 正确率，GPT-5.6 Sol 约 55%，DeepSeek V4 Flash 0731 达到 64.6%。这个分数已经超过了很多人类测试者。

💡 为什么这对你重要

  • 如果你在用 vibe coding（用自然语言描述需求让 AI 写代码），模型的推理能力直接决定了它能否理解复杂需求
  • DeepSeek V4 Flash 的 API 价格只有 GPT-5.6 Sol 的 1/10，性价比极高
  • ARC Prize 的高分意味着模型在「举一反三」方面有实质进步，不只是记忆训练数据
  • 如果 DeepSeek 持续领先，你的 agent 工作流可能需要考虑切换默认模型
🎯 你今天就能做的事
  1. 去 ARC Prize 排行榜看看具体分数和推理示例：arcprize.org
  2. 如果你有 GPU（16GB+ VRAM），试试本地部署：ollama pull deepseek-v4-flash-0731
  3. 在 Claude Code 或 Codex 中切换模型试试，对比一下复杂推理任务的表现
  4. 关注 Terminal-Bench 分数——这是 agent 工具调用能力的指标，直接关系到你的编码体验

Anthropic 默认开启 Claude Code 自动模式，安全评估显示比人类更可靠

clawii，你每天用 Claude Code 写代码，现在它默认用自动模式了。Anthropic 今天宣布，从 8 月 14 日起，Pro、Max 和 Team 计划的 Claude Code 新会话将默认启用自动模式。他们还发布了安全评估：在 1,053 名付费测试者中，只有 13.6% 的人类拒绝了危险操作，而自动模式能阻止 89% 的此类操作。

📌 背景：自动模式让 Claude 在不需要每次确认的情况下执行操作，但 Anthropic 声称已经「基本缓解了所有攻击」，包括提示注入和数据泄露。Cat Wu（Anthropic 产品负责人）在 AI Engineer World's Fair 上说：「在 Anthropic 内部，几乎每个人都用自动模式。」

💡 为什么这对你重要

  • 自动模式能显著提升编码速度——你不需要每次操作都点确认
  • 安全评估显示自动模式比人类更可靠——人类在 86.4% 的情况下会批准危险操作
  • 如果你担心安全性，Anthropic 的评估数据可以作为参考
  • 这个趋势意味着其他 AI 编码工具也可能跟进默认自动模式
🎯 你今天就能做的事
  1. 如果你有 Claude Code，在设置中提前开启自动模式体验一下
  2. 读 Anthropic 的安全评估原文，了解他们如何缓解提示注入风险
  3. 在你的工作流中测试自动模式——从简单的重构任务开始
  4. 关注 8 月 14 日的正式变更，看看是否有额外的安全选项
