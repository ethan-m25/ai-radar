Muse Code + Muse Spark 1.2：Meta 正式发布编码 Agent

爪哩，Meta 今天发布了 Muse Code（beta）和 Muse Spark 1.2，正式进入编码 Agent 赛道。Muse Code 是一个专门为编码任务优化的模型，与 Muse Spark 1.2 联合训练，主打长序列 Agent 工具调用。Simon Willison 已经上手测试，生成了一只 SVG 鹈鹕。定价方面，如果你同意让 Meta 用你的数据，价格可以低到 $0.10/$0.20 每百万 token——比 GPT-5.6 Luna 还便宜。

📍 背景 · 编码 Agent 赛道目前由 Claude Code（Anthropic）和 Codex（OpenAI）主导。Meta 之前有 Muse Spark 系列模型，但一直没有专门的编码 Agent。Muse Code 的发布意味着 Meta 正式入局，而且采用了"联合训练"策略——Muse Code 和 Muse Spark 1.2 一起训练，确保编码能力和通用 Agent 能力协同优化。定价策略也很激进，贡献者价格接近成本价。

为什么这事重要

  • Meta 正式入局编码 Agent — 现在三大巨头（Anthropic、OpenAI、Meta）都有了自己的编码 Agent。竞争加剧意味着价格会继续下降，功能会加速迭代。
  • 激进的贡献者定价 — $0.10/$0.20 每百万 token 的价格比 GPT-5.6 Luna（$0.20/$1.20）还便宜，如果你不介意数据被 Meta 用于改进产品。标准价格 $1.25/$4.25 也很有竞争力。
  • 联合训练策略 — Muse Code 和 Muse Spark 1.2 一起训练，意味着编码能力和通用 Agent 能力是协同优化的，而不是两个独立模型。
  • Simon Willison 已测试 — 他用 Muse Spark 1.2 生成了一个 SVG 鹈鹕，效果比 1.1 版本有明显提升。说明模型确实可用。

Cloudflare OS：开放 Agent 平台，567 分 HN

爪哩，Cloudflare 今天发布了 Cloudflare OS，一个面向 Agent、应用和工作的开放平台。HN 上 567 分，274 条评论。Cloudflare 正在从 CDN/安全公司转型为 AI Agent 基础设施提供商。这个平台可能让你直接在 Cloudflare 的边缘网络上运行 Agent，无需自己管理服务器。

📍 背景 · Cloudflare 过去几年一直在扩展其平台能力，从 CDN 到 Workers（边缘计算）、D1（数据库）、R2（对象存储）、AI Gateway 等。Cloudflare OS 是这些能力的整合——一个统一的平台，让开发者可以构建、部署和运行 AI Agent，利用 Cloudflare 的全球边缘网络。这是 Cloudflare 在 AI 基础设施领域的重要布局。

为什么这事重要

  • Agent 基础设施平台化 — Cloudflare OS 提供了一个完整的 Agent 运行环境，包括计算、存储、网络和安全。你不需要自己管理服务器或 Kubernetes。
  • 边缘网络优势 — Cloudflare 有全球 330+ 个边缘节点，Agent 可以在离用户最近的地方运行，延迟极低。
  • 开放平台 — 支持多种模型和框架，不锁定特定供应商。你可以用 Claude、GPT、Muse 等模型。
  • 对你的意义 — 如果你在构建需要低延迟的 Agent 应用（比如客服、自动化工具），Cloudflare OS 可能比自建服务器更简单、更便宜。

老实说：Cloudflare OS 目前还是早期阶段，具体的能力边界和定价还不完全清楚。它的最大优势是 Cloudflare 的全球边缘网络——如果你的 Agent 需要服务全球用户，延迟优势很明显。但如果你只需要在单一区域运行，Modal 或 Baseten 可能更成熟。另外，Cloudflare 的 AI 相关产品（AI Gateway、Workers AI）之前有一些限制，比如模型选择不够丰富，希望 Cloudflare OS 能改善这一点。

🔭 关注点 · 关键 trigger event：Cloudflare OS 的具体定价和可用性；社区是否出现成功案例；是否支持 GPU 加速；与 Cloudflare Workers 的集成深度。
术语解码 · 边缘网络（Edge Network） = 分布在全球各地的服务器节点，用户请求会被路由到最近的节点处理，延迟更低。Agent 基础设施 = 运行 AI Agent 所需的所有底层服务，包括计算、存储、网络、安全等。
