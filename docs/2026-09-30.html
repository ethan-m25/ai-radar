GPT-6.1 Sol — 接近 Astra 智能，五分之一价格

OpenAI Dots — 永远在线的代理

clawii，OpenAI 今天发布了 Dots——一种「永远在线」的 AI 代理。你给它一个任务，它会在后台持续运行，不需要你一直盯着。HN 上 642 分、502 条评论，讨论热度很高。

AI 代理（Agent）是 2026 年的主旋律。Meta 刚发了 Muse（个人代理），Anthropic 有 Claude Code 的持续运行模式，现在 OpenAI 也加入了。Dots 的卖点是「always-on」——你布置任务后关掉电脑，它自己会继续工作，完成后通知你。这对非开发者来说可能是最实用的代理形态。

为什么这事重要

  • 「设置后忘记」模式 — 不像 ChatGPT 需要你一直对话，Dots 是异步的。你给它一个目标（比如「每天监控竞品价格变化，有异常通知我」），它自己会持续运行。
  • 对非开发者友好 — Dots 是用自然语言配置的，不需要写代码。clawii 可以用它来自动化很多工作流，比如每周自动汇总团队绩效数据、监控薪酬市场报告更新。
  • OpenAI 正式入局代理赛道 — 之前代理主要是第三方工具（比如 AutoGPT、CrewAI）或 Anthropic 的 Claude Code。OpenAI 的入局意味着代理会成为 ChatGPT 的核心功能，而不是附加功能。

🎯 今天就能做的事

  1. 打开 ChatGPT，看看有没有 Dots 的入口（可能在侧边栏或设置里）。目前是逐步推送，不一定所有人都有。
  2. 想一个你每周都要做的重复性任务（比如「每周五汇总团队加班数据」），试试用 Dots 配置成自动运行。
  3. 去 OpenAI 官方页面 看 Dots 的详细介绍和用例。

跑在什么之上: Dots 运行在 OpenAI 的云端基础设施上，底层模型是 GPT-6 系列（具体版本未公布）。它通过 ChatGPT 界面访问，不需要额外安装。

上手难度: 低。如果你会用 ChatGPT，就会用 Dots。区别是你不需要一直在线等回复——布置任务后可以关掉页面，Dots 完成后会通过通知或邮件提醒你。

你能拿它做什么: 对 clawii 来说，最实用的场景可能是「定时数据监控」——比如设置一个 Dots 每周一自动拉取各部门的薪酬数据，和行业基准对比，生成差异报告。或者设置一个 Dots 监控公司内部的政策更新文档，有变化时自动总结并推送给你。

诚实警告: Dots 目前是初期版本，可能会有可靠性问题（比如长时间运行后上下文丢失、任务中断）。另外，always-on 意味着一直消耗 API 额度，要注意成本控制。

🔭 下次拍肩膀的触发条件: 如果 Dots 开放了 API 或第三方集成（比如连接 Google Sheets、Slack、邮箱），那它的实用性会大幅提升。另外，如果出现「Dots 市场」——用户可以分享和下载预配置的 Dots 模板——那会是代理生态的一个重要里程碑。

术语解码:

Always-on agent = 永远在线的代理。和传统 AI 对话不同，你不需要每次手动启动，它会在后台持续运行，像有一个虚拟助手在帮你盯着事情。

异步任务 = 你发出指令后不需要等待结果，可以去做别的事，完成后它会通知你。和「同步」（必须在线等回复）相反。
