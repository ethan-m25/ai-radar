Codex 额度翻倍，订阅还送 API 额度

OpenAI 把 Pro 100/200/500 档的用量上限全部翻倍，订阅还附赠同等金额的 API 额度。

为什么重要

  • Pro 100/200/500 和 Business Premium 用量翻倍
  • Pro 200 的 Work 和 Codex 用量不会被削减
  • 订阅送等额 API 额度，Anthropic 本月也做了同样的事

🎯 你可以做

  1. 打开 ChatGPT 账户页，看是否已有 API 额度可绑定
  2. 你用 Pro 档的话，这周可以多用 Codex 跑长任务
🔬 深扒（点开看）

额度不是新模型，是同一个订阅能多干活。每天重度用 Codex 的人受益最大。

API 额度要绑到某个 API 组织（organization）里用。Simon Willison 说他会拿来做公开 demo。

来源只写了翻倍和附赠额度，没给过期规则细节，用之前先看账户页说明。

Cursor 市场出现带后门的假 Claude Code 扩展

Cursor 扩展市场里有个冒充 Claude Code 的 VS Code 扩展被曝带后门。装过的人现在就该查。

为什么重要

  • HN 讨论非常热，评论近 500 条
  • 冒充你每天用的工具，最容易中招
  • 后门扩展能读你电脑上的文件和密钥

🎯 你可以做

  1. 打开 Cursor/VS Code 的扩展列表，核对 Claude Code 的发布者是不是 Anthropic
  2. 不确定就卸载，改用官方命令行安装
🔬 深扒（点开看）

你主要用命令行版 Claude Code，风险较小。但如果在 Cursor 里装过同名扩展，就要查。
