Kimi K3 正式开源 — 382 points，HuggingFace 发布，中国最强开源模型之一

爪哩，今天（7/27）是 Kimi K3 开源的大日子。Moonshot AI 按时在 HuggingFace 上发布了完整权重，HN 头条 382 分/166 评论。这是目前最强的开源权重模型之一，2.8T 参数、1M 上下文、原生多模态、Apache 2.0 许可。对你来说，这意味着你可以本地部署一个接近 Claude Fable 5 水平的模型，而且完全可控。

📍 背景 · Kimi K3 于 7 月 16 日首次公开，当时承诺 7 月 27 日开源。今天 Moonshot 准时兑现。模型采用 MoE 架构（2.8T 总参数，约 41B 激活），使用创新的 Kimi Delta Attention（KDA）实现 6.3x 解码加速。在多个人工评测中，Kimi K3 在编程和 agent 任务上接近 Claude Fable 5 和 GPT-5.6 Sol，领先于 Opus 4.8。之前我们一直在 Still tracking 中跟踪了 10 天，今天正式发布是确凿的 trigger event。
Kimi K3 (2.8T) 2.8T
Claude Opus 5 ~2T（估计）

为什么这事重要

  • 开源模型的天花板被打破 — Kimi K3 是第一个在多个独立评测中达到 Frontier 级别的开源模型（Intelligence Index 57，接近 Fable 5 的 59 和 Opus 5 的 58）。你不需要再依赖闭源 API 才能获得顶级能力。
  • 权重完全可控，价格为零 — Apache 2.0 许可意味着你可以商用、自托管、微调。对于企业级应用（特别是敏感数据）来说，这是个巨大的吸引力。
  • 对中国用户极友好 — 中文能力是原生优势，上下文 1M token 适合处理长文档。如果你在做中文处理或需要长上下文，这可能是比 Claude 更好的选择。
  • 生态已经就绪 — HuggingFace、vLLM、Ollama 等平台已经支持。你能在 5 分钟内跑起来。
🎯 今天就能做的事
  1. 去 HuggingFace 下载权重 — huggingface.co/moonshotai/Kimi-K3。2.8T 完整权重需要至少 5TB 存储（FP16），但 MXFP4 量化版只用 ~700GB。
  2. 在本地跑推理 — 用 vLLM 或 Ollama 加载。即使你只有单卡 A100（80GB），也可以跑量化版试试效果。
  3. 试试 API 提供商 — 如果本地资源不够，Fireworks、Together、Depth 等平台已经上线了 Kimi K3 的 API，价格大约 $0.5/M tokens。
  4. 关注后续评测 — Simon Willison 今天还在 kayaking，但他明天很可能出详细评测。如果你用 Claude Code，可以试试把 Kimi K3 作为替代模型。

老实说：Kimi K3 不是完全超越 Fable 5，它在某些 agent 任务上落后，但在编程和中文处理上非常接近。最大的优势是开源自托管。如果你不需要最新最强的闭源模型，Kimi K3 可能是更好的性价比选择。但部署成本不低——完整权重需要多张 A100，量化版可以用单张。

🔭 关注点 · 关键 trigger events：1) Simon Willison 发布详细评测（预计明天）；2) Cursor/Claude Code 是否官方支持 Kimi K3；3) 社区发现任何重大限制。如果评测认为"Kimi K3 在 vibe coding 上完全替代 Opus 5"，信号升级。
术语解码 · MoE = Mixture of Experts，混合专家架构，只激活一部分参数，提高效率。MXFP4 = 4-bit 浮点量化，可以将模型大小缩小到原来的 1/4。KDA = Kimi Delta Attention，Moonshot 的注意力优化，实现更快的解码。Apache 2.0 = 宽松的开源许可，允许商用和修改。
